# 이야기 연결 구현 — 2026-11-20

## 범위

‘미완성 마을 그림을 완성하는 시간 여행’을 현재 8개 미니게임에 연결했다. 역사적 활동·수치·판정은 기존 chapters.js와 각 놀이를 유지하고, 창작 화자 ‘나’와 시대별 주민의 대화를 추가했다. 새로운 교과서 전수 대조를 수행한 작업은 아니다.

진행: 그림첩 홈 → 박물관 도입 → 시대 표시 → 주민 부탁 → 놀이 → 주민에게 돌아가기 → 기억 남기기 → 그림 복원 → 다음 시대. 여덟 기억 뒤 박물관으로 돌아오는 결말을 제공한다.

- 대사는 한 화면에 한 발화씩 나타나며 이전 대사로 돌아갈 수 있다. 컷신 영상과 자동 넘김은 없다.
- 화면의 ‘놀이 골라하기’에서 기존 8개 놀이를 자유롭게 재시도할 수 있다.
- 이야기 진행은 `story.started/memories/phase/line`으로 저장한다. 놀이 기록과 이야기 속 그림 복원은 구분한다. 기존 놀이를 이미 끝냈더라도 새 이야기의 주민 대화가 생략되지 않는다.
- 그림은 기존 마을 삽화의 여덟 영역에 색이 돌아오는 방식이다. 새 인물 자산 제작이나 장면 속 모든 소품의 개별 상태 변화는 이번 범위가 아니다.
- 시대별 여행임을 표시한다. 동일한 사람이 수백 년을 살았다고 묘사하지 않으며, 6장 문제를 해결하자 7장 사회 전체가 평온해졌다는 인과를 피한다.
- 놀이 중 복귀하면 해당 장 시작 안내로 돌아간다. 곡식 창고는 기존 체크포인트를 사용한다. 다른 놀이의 모든 중간 상태를 저장하지는 않는다.

## 검증

실제 Chrome + Playwright, 로컬 HTTP에서 `tests/story-flow.cjs`로 도입 → 8개 도움 모드 놀이 → 각 주민 대화 → 여덟 영역 복원 → 결말 → 새로고침 → 놀이 메뉴를 버튼 클릭·키 입력으로 통과했다. 완료 상태나 게임 시계를 주입하지 않았다. 도입 후 첫 장의 대화 도중 새로고침하여 같은 대사로 이어지는 것도 확인했다.

1024×768에서 각 장의 대화·복원·결말을 확인했다. 768×1024와 1366×768에서는 홈·도입·첫 장 대화 화면을 확인했다. 검사한 요소의 잘림과 페이지 넘침은 관찰되지 않았다. 홈·농민 대화·결말 캡처를 육안으로 확인했다.

기존 기본 놀이 검사와 손상 저장·지연 재개 5건도 통과했다. 학생 이해도·재미, 실제 기기, 전체 장면의 모든 화면 크기 조합은 미검증이다. 자유 이동, 클릭해서 주민 발견, 관계 분기, 새로운 캐릭터 모션 제작은 후속 범위다.

배포 소스 `2db0b7660786d257551eb32ecca8b9c1b085daf2`의 배포 상태 `succeeded`를 확인했다. 실제 비공개 배포 URL에서도 `LIVE_STORY=1`로 같은 통합 검사를 재실행하여 8개 도움 모드 놀이·복귀 대화·그림 복원·결말·저장·선택 메뉴와 위 세 크기의 해당 화면을 통과했다. 페이지 오류·실패 HTTP 응답은 기록되지 않았다. 공유 범위는 변경하지 않았다.
