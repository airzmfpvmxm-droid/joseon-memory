## 확인 자료와 범위

로컬 교과서 펼침 이미지 `textbook-check/spread-36.jpg`~`spread-48.jpg` 총 13장을 직접 열어 인쇄 78~103쪽을 확인했다. 프로젝트의 CHAPTERS.md, PROJECT.md, HANDOFF.md도 읽었다. 게임 코드·이미지·음원은 제작하지 않았다. 참고 영상의 재생 내용 및 실제 플레이는 이 검토에서 확인하지 않았다.

미니게임은 이야기 속 작은 도움과 체험이다. 성공은 해당 인물의 구체적 부탁을 해결하고 장면을 조금 변화시킨다. 실패는 연습과 재시도를 뜻한다. 실제 전쟁의 결과, 정치 개혁의 성패, 신분 질서나 부패의 해결을 학생의 반사신경 점수로 판정하지 않는다.

## 유지해야 할 챕터별 학습 범위

미니게임 한 종이 해당 장의 학습 전체를 대체하지 않는다. CH02에는 법전·세종 때 과학과 편찬, CH03에는 서원·신분·관혼상제, CH04에는 두 전쟁과 이후 생활, CH05에는 붕당·탕평·정조·세도 정치, CH07에는 농업·신분 변화와 다양한 서민 문화, CH08에는 천리경 외 자명종·곤여만국전도·천주실의의 소개가 남아야 한다. 새 미니게임 때문에 이 사건·관찰을 삭제하지 않는다.

세종 때 글자 학습 성공만으로 모든 백성이 곧바로 문해력을 갖게 되었다고 말하지 않는다. 지붕 수리 성공으로 신분 차별이 사라졌다고 말하지 않는다. 화성 돌수레의 균형은 운반 방법의 결과만 설명한다. 전쟁 보급 운반 성공을 이순신의 모든 승리나 전쟁 종결의 원인으로 대체하지 않는다.

## CH06 추가 검토 기준

1. 보존 표본(`ch06_grain_sample`)과 연습용 곡식은 다른 대상 ID·그릇·이름을 사용한다. 피해 표본은 분류·섭취·폐기하지 않는다.
2. 계량 성공은 단위 이해 또는 연습 완료다. 10되를 새로 재어 봄에 실제 지급된 양을 증명했다고 기록하지 않는다.
3. 기록상 게임용 약정 10+1=11, 요구 15, 개인 추가 4의 가상 설정과 근거 판정을 유지한다. 이자 자체만으로 부정을 단정하지 않는다.
4. '좋은 곡식만 골랐으니 부패 해결' 결말을 쓰지 않는다. 조사·비교·농민 보고를 거쳐도 제도 전체 해결을 선언하지 않는다.
5. 새 캐주얼 게임의 결과와 기존 필수 조사·보고 완료는 별도 저장 상태로 관리한다. 연습의 점수가 역사적 판단의 정오를 덮어쓰지 않는다.
