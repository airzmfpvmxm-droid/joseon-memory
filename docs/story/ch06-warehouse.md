# CH06-001 — 봄에 빌린 곡식: 창고 시범 구간

작성: 01 스토리·역사 검토 / 2026-11-18 / 초안 v0.3
기준: 운영 v1.0, 스토리 초안 v0.1. 04 게이밍 담당과 수치·근거·단계 교차 협의 완료. 총괄 통합 전 제안 명세다.

## 1. 확인한 자료와 역사 범위

- 로컬 `sources/사회(5-2 천재).pdf`가 존재함을 확인했다. 이 작업에서는 원본 PDF를 다시 추출하지 않고, 해당 교과서의 로컬 펼침 이미지 `textbook-check/spread-45.jpg`(인쇄 96~97쪽), `spread-46.jpg`(98~99쪽)를 직접 열어 확인했다.
- 96쪽: 탕평책·정조의 개혁 이후, 왕권이 약해지고 왕실과 혼인 관계를 맺은 일부 가문의 세도 정치가 이루어지는 흐름.
- 97쪽: 관직 매매와 부패한 관리, 과도한 징수와 백성의 고통. 농사짓지 못하는 땅의 세금, 곡식 대여의 부정 운영, 어린아이·죽은 사람에게 군포를 매기는 사례가 제시된다. 곡식 사례에는 억지 대여·벌레 먹은 곡식·이자 부담이 포함된다.
- 98쪽: 벽에 방을 붙이거나 세금 납부 거부, 농민 봉기 등 백성들의 저항. 정부의 대응에도 큰 효과를 거두지 못한 한계. 홍경래의 난(1811년)과 진주 농민 봉기(1862년)는 서로 구분한다.
- 시범 구간은 위 사례 중 곡식 창고 사건만 다룬다. 19세기 가상 마을의 가상 인물과 사건이다. 특정 봉기의 직접 원인을 이 사건 하나로 설명하지 않는다.
- 참고 영상의 재생 내용은 이 작업에서 확인하지 않았다. 영상과 동일한 연출이라는 주장은 하지 않는다.

## 2. 학습과 서사 목표

플레이어는 피해 농민의 말을 듣고 처음의 대여 조건과 현재 요구를 비교한다. '빌린 양보다 많이 갚는다'는 이유만으로 부정이라고 판단하지 않고, 약정과 관계없이 관리가 개인 몫을 붙인 근거를 찾아 설명한다.

그림 복원의 변화: 창고 건물만 남아 있던 그림에 농민의 얼굴과 손이 다시 나타난다. 개인의 말을 듣고 근거를 남긴 일의 의미를 보여 준다. 이 행동으로 제도 전체가 즉시 고쳐지거나 모든 부채가 사라지지는 않는다.

## 3. 창작 수치와 증거 설정

아래 숫자와 문서 내용은 학습을 위한 가상 사례이며 실제 사료의 인용·조선 전체의 표준 이율이 아니다. 이 구분은 제작 명세·교사용 해설에 남긴다. 장면 속 문서에는 '게임용으로 만든 문서' 같은 설명을 인쇄하지 않는다.

| 항목 | 설정 | 역할 |
|---|---|---|
| 봄에 지급된 양 | 10되 | 농민 증언과 봄 기록이 일치 |
| 처음 안내된 이자 | 1되 | 이자가 있다는 사실 자체를 부정으로 취급하지 않음 |
| 처음 약속한 갚을 양 | 11되 | 10+1의 비교 기준 |
| 가을에 요구한 총량 | 15되 | 농민이 갖고 온 요구 쪽지 |
| 추가 요구 행 | 아전의 몫 4되 | 약정과 무관한 관리 개인의 추가 요구임을 명시 |
| 벌레 먹은 곡식 표본 | 농민이 봄부터 보관해 둔 작은 꾸러미 | 부정 운영 맥락의 보조 근거. 최초 지급량이나 추가 4되의 증거를 대신하지 않음 |

문서를 읽기 전에 사실을 단정하지 않는다. 숫자가 다르다는 발견과 '어떤 추가 요구가 잘못됐는가'를 설명하는 단계를 연결한다.

## 4. 인물·공간·소품

- 장면 `ch06_warehouse`: 늦가을 낮, 창고 출입문 옆. 왼쪽 농민, 뒤쪽 낮은 탁자, 탁자 위 대여 기록, 농민 옆 바닥 작은 곡식 꾸러미. 동선과 최종 좌표는 02가 확정한다. 표본 기준 앵커는 장면 좌표 (.43,.89)이며 대사와 몸짓도 농민 옆 바닥을 가리킨다.
- `ch06_farmer`: 막동. 가상 농민. 창고에 이미 보이는 인물이며 자루를 쥐고 움츠린 자세. 대화를 시작하면 얼굴을 든다. 종료 후 완전히 환하게 웃기보다 몸을 펴고 플레이어를 바라본다.
- 담이·여행자: 기존 동행 인물. 새로운 전신 자산이 필수인 것은 아니며 대화 표현 방식은 총괄·02가 결정한다.
- `ch06_loan_record`: 탁자 위 열린 대여 기록. 본인 이름·봄 지급량·이자·상환량이 같은 행에 있음. 관아 원본을 줍거나 없애지 않는다. 펼침·관찰 상태만 변화한다.
- `ch06_demand_note`(신규 제안): 농민이 갖고 온 가을 요구 쪽지. 대화 후 농민이 손에 펼쳐 보여 준다. 별도 쪽지 클릭 영역은 만들지 않고 농민 대화와 조사 자료에서 연다. 원본을 받거나 인벤토리에 넣지 않는다. 비교 화면에서는 조사한 내용의 기록으로 다시 본다. 원본은 계속 농민에게 남는다.
- `ch06_grain_sample`: 농민 옆 바닥 작은 묶음. 조사하면 펼쳐 벌레 먹은 흔적을 관찰하고, 빌릴 때부터 이런 상태였다는 농민의 증언과 연결한다. 닫을 때 제자리에 놓는다. 맛보거나 먹지 않는다. 살아 움직이는 벌레의 확대 연출은 필요하지 않다.
- `ch06_measure`: 되 모양의 계량 도구. 단위를 살피는 일반 관찰용. 선택 임무이며 필수 조건으로 추가하지 않는다. 바닥의 곡식을 재서 봄의 10되를 증명했다고 표현하지 않는다.

대화는 한 상자 1~2문장, 약 45자 내외를 목표로 나눈다. 목표 문장은 항상 '누구에게/어디에서/무엇을' 할지 구체적으로 안내한다. 문서·비교는 태블릿 한 화면 겹창에서 열고 페이지 전체를 밀어내지 않는다.

## 7. 부서 인계와 완료 판정

- 04와 합의: 10+1=11, 요구 15, 개인 추가 4. 필수 조사는 봄 기록·요구 쪽지·곡식 표본. 표본을 전체 대여량의 증거로 쓰지 않음. 비교 후 주민 보고 필수.
- 02 요청: 농민이 첫 진입부터 보일 것. 손짓의 목적지와 기록 위치를 일치시킬 것. 탁자·손·바닥 소품의 접점과 터치 영역을 맞출 것. 새 쪽지 ID가 필요하다.
- 03 요청: 곡식 표본 관찰에는 마른 곡식의 작은 소리, 농민 대사에는 과도한 슬픔·위협 음악을 피할 것. 성공은 문제 전체 해결을 암시하는 승리 팡파르 대신 작은 확인음.
- 05 요청: '어디서 갚을 양을 확인하는가'를 농민 대사만 읽은 학생이 찾을 수 있는지, 농민 누락·가려짐·자료 순서의 막힘을 점검할 것.
- v0.3 교차검토 반영: 총괄 최종 INT-001에 따라 표본은 농민 옆 바닥 (.43,.89)으로 위치·대사·몸짓을 통일. 쪽지는 농민 손에서 펼치고 소유 유지, 별도 쪽지 클릭 영역 없이 농민 대화/조사 자료로 열람. 보고 후 앉은 채 몸을 조금 편다. QA ST-01/02 대응.
- 문서상 완료: 증거와 대사·반복·진행 한계 명시. 미완료: 구현, 자산 제작, 실제 플레이, 터치·키보드·저장 테스트. 이 문서는 실제 역사 연구자 감수 또는 학생 사용성 검증을 완료했다고 주장하지 않는다.
