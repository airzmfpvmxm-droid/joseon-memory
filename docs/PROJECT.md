# 조선의 기억 — 사람들이 살아간 나라

운영 기준: v1.0 / 2026-11-18

## 프로젝트 정의
- 대상: 초등학교 5학년.
- 형태: 이야기 중심의 싱글 탐험 RPG.
- 학습 범위: 사회(5-2 천재) 교과서 인쇄 쪽수 78~103쪽.
- 서사 기준: 미완성 마을 그림을 완성하는 시간 여행 초안. 장별 상세 대사와 미션은 검토 대상이다.
- 분위기 참고: 『짱구는 못말려! 탄광마을의 흰둥이』. 참고 영상: https://www.youtube.com/watch?v=W1pk6SokvWs
- 참고할 요소: 풍경 탐험, 주민과의 관계, 자연스러운 인물·소품, 작은 움직임과 환경음, 편안한 대화·발견의 속도.
- 영상 확인 상태: 재생 내용을 직접 확인하지 못함. 관찰 근거 없는 분석을 확정하지 않는다.
- 배경·캐릭터·음악은 독자 제작한다. 컷신 영상은 제외한다.

## 공통 원칙
1. 태블릿 한 화면에 게임 화면과 주요 UI가 들어온다. 페이지 전체 스크롤을 사용하지 않는다. 지도·자료·설정은 겹창과 페이지 전환을 사용한다.
2. 주민이 사건을 직접 이야기한다. 문서·물건은 증언을 확인하는 근거다.
3. 클릭 대상은 장면 속 인물과 실제 소품이다. 이모지·중복 아이콘·사각 임시 버튼을 배경에 덧씌우지 않는다.
4. 주운 종이 제거, 자루 이동, 호소문 부착 등 행동 결과가 장면에 남고 저장된다.
5. 컷신 영상 없이 대화·인물 이동·표정·소품 변화로 사건을 전달한다. 작은 손짓·물결·나뭇잎·연기 등 반복 동작은 허용한다.
6. 역사적 사실과 창작 설정을 구분한다. 시대 이동을 표시한다. 작은 미션이 역사 전체를 해결했다고 표현하지 않는다.
7. 학습 내용이 판단과 행동에 연결되게 한다.
8. 실제 검증한 환경·구간·결과·미확인 범위를 구분해 보고한다.

## 세션과 권한
| 세션 | 책임 | 산출물 |
|---|---|---|
| 00 총괄 기획·제작 | 목표·범위·우선순위, 부서 조율, 시스템 통합·배포 관리 | 공통 기준, 작업 지시, 확정 기록, 통합 버전 |
| 01 스토리·역사 검토 | 서사·인물·대사·교과서 대응 검토 | 장별 시나리오·대사·사건 조건 |
| 02 그래픽·UI 엔지니어링 | 이미지·배치·화면·반응형 UI·작은 동작 | 자산·배치 규격·UI 구현 |
| 03 사운드 | 배경음악·환경음·효과음·재생 규칙 | 음원·이벤트 연결·음량 명세 |
| 04 게이밍·미니게임 | 탐험·미션·규칙·난이도·힌트 | 플레이 설계·성공/재시도 조건 |
| 05 UX·QA | 실제 플레이·접근성·가독성·오류 검증 | 재현 절차·증거·우선순위 |

스토리는 새 기능을 총괄에 요청한다. 그래픽은 학습 내용과 진행 규칙을 임의 변경하지 않는다. 사운드는 공통 ID에 연결한다. 게이밍은 제작 비용과 다른 부서 영향을 제시한다. QA는 관찰 사실과 제안을 구분한다. 사용자가 확정한 사항은 총괄도 임의로 번복하지 않는다.

## 협업 방식
- 별도 대화 세션은 최신 대화나 변경 사항을 자동 공유한다고 가정하지 않는다.
- 이 문서와 DECISIONS.md, TASKS.md, HANDOFF.md의 지정 버전을 각 세션이 읽는다. 접근할 수 없으면 최신 문서 또는 인계문을 전달받는다.
- 총괄 지시 → 담당 제작 → 총괄 통합 → UX 검증 → 수정 → 버전 확정.
- 파일 담당을 나누고, 동시 수정이 필요하면 브랜치를 분리한다. 다른 작업을 덮어쓰지 않는다.
- 현재 저장소의 기존 게임은 참고 구현이다. 새 프로젝트 기준을 등록하는 것만으로 기존 게임이나 운영 사이트를 교체하지 않는다.
- 작업지시 양식: templates/TASK.md. 세션 시작 지시문: sessions/README.md.
