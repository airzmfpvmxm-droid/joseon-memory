# 공통 식별자와 데이터 관리

이 문서는 새 프로젝트의 명세다. 기존 코드에 같은 데이터 구조가 구현되어 있다고 가정하지 않는다.

- 챕터: ch06
- 장면: ch06_warehouse
- 인물: ch06_farmer
- 소품: ch06_loan_record, ch06_grain_sample, ch06_measure
- 대사: ch06_farmer_intro_001
- 이벤트: ch06_farmer_talked, ch06_record_checked, ch06_grain_checked, ch06_comparison_completed
- 음향: aud_ch06_warehouse_ambience, aud_grain_pour

## 대상별 필수 관리 정보
ID, 장면 ID, 배경 속 기존 물건/별도 이미지 여부, 이미지 경로, 표시 크기, 기준 좌표계와 바닥 접점, 클릭 영역, 반짝임 위치, 표시 조건, 상호작용 조건, 접근성 이름, 획득·사용 후 모습, 연결 이벤트, 저장 키.

- 그림·클릭 영역·반짝임은 같은 장면 좌표계를 사용한다.
- 이미지가 없으면 공통 이모지로 대체하지 않는다. 출시 검사에서 누락을 오류로 보고하고, 실제 화면에서는 보이지 않는 오브젝트가 진행을 막지 않게 복구 경로를 제공한다.
- 순서가 있는 활동은 현재 대상, 병렬 조사 활동은 미확인 대상만 은은하게 반짝인다.
- 목표 터치 영역 44×44 CSS px 이상. 작은 물건은 확대 조사 창 등으로 인접 영역 겹침을 해결한다.
- 상태 예시: 주민 미대화 → 조사 가능 → 기록·곡식 확인 → 비교 가능 → 주민에게 보고 → 완료.
- 저장 스키마 버전과 기존 게임 저장 데이터의 호환 여부는 총괄이 구현 전에 확정한다.
