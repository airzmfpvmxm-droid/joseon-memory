## 2026-11-19 / 플레이 버전 v0.1.0
- 사용자 구현 요청에 따라 8개 미니게임을 실제 HTML/CSS/JavaScript로 제작했다. 진입 대화·완료 회고·개인 기록·음소거·진행 저장·도움 모드·일시정지를 공통 화면으로 연결했다.
- 구현 파일: index.html, js/app.js, js/chapters.js, js/audio.js, js/games/*.js, css/*.css, assets/.
- 각 장은 최초 화면에서 모두 선택할 수 있다. 이 버전은 놀이와 이야기 연결을 체험하는 플레이 버전이며 장편 RPG 전체의 자유 탐험·관계·퀘스트 분기를 모두 완성한 최종판은 아니다.
- 기존 생성 배경을 재사용·분할하고 오브젝트는 SVG/CSS로 제작했다. 합성 박자·효과음은 독자 제작했다. 출처는 ASSETS.md.
- 실제 검증 결과와 미확인 범위는 qa/IMPLEMENTATION-TEST.md. 실제 태블릿 손가락 조작·학생 재미·학습 효과·스피커 청취는 별도 과제다.
- 신규 호스팅은 소유자 전용으로 배포한다. 학생 공유가 필요하면 접근 범위를 별도로 결정한다. 기존 joseon-village 사이트는 변경하지 않는다.
- 다음 단계: 사용자 플레이 피드백으로 난도·화면·동작 조정, 긴 탐험 장면·NPC 관계와 장별 역사 자료 보강.

## 2026-11-19 / 운영 v1.2 / 캐주얼 미니게임 보완
- 사용자 요청: 실제로 즐길 수 있는 퍼즐·리듬·레이싱 등 다양한 미니게임을 넣도록 보완.
- 총괄+5개 전문 담당이 8장별 규칙과 구현 계약을 작성하고 교차검토했다. 담당별 피드백과 반영 근거는 qa/casual-minigames-review.md 및 각 문서에 기록한다.
- 8장 활동: 길 연결 / 자모 조립 / 지붕 수리 / 보급품 레이싱 / 돌수레 균형 / 곡식 분류·계량 / 장터 리듬 / 천리경 관찰.
- 기존 스토리와 역사 내용은 유지한다. 미니게임의 손기술 점수는 역사 이해도 평가와 구분한다.
- 보조 모드로 같은 필수 활동을 수행하면 이야기·보상을 동등하게 제공한다. 시간 종료만으로 학습을 자동 완료하지 않는다.
- 다음 작업: 공통 엔진과 6장 분류·계량을 연결한 최초 데모 구현, 다음으로 7장 리듬과 4장 레이싱.
- 이 사이클은 기획 보완이다. 코드·완성 자산·음원·실제 플레이 데모·태블릿 검증은 아직 없다. 영상 직접 관찰도 미확인 상태다.
- 별도 사용자 대화방은 없으며 이번 요청 처리 중 하위 에이전트가 협업했다. 응답 종료 뒤 자동 작업이 계속되는 것은 아니다.
