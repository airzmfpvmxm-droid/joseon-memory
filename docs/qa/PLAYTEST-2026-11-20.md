# 조선의 기억 플레이 검증 — 2026-11-20

검사 대상: 현재 구현된 8개 미니게임과 시작·결과 대화, 홈, 저장, 일시정지. 전체 탐험 RPG 서사 완성을 검증한 것은 아니다.

실행 방법: 실제 Chrome을 Playwright로 조작하여 화면 버튼 클릭·키보드 입력·터치 에뮬레이션을 수행했다. 완료 플래그나 게임 시계를 바꿔 통과시키지 않았다. 손상 저장·오디오 지연 검사는 별도 오류 주입 검사로 구분했다.

## 발견하고 수정한 오류

| 문제 | 재현 결과 | 수정 후 같은 절차 |
| --- | --- | --- |
| 저장 값 `completed:true` 또는 `best:"bad"` | 놀이를 끝낼 때 TypeError, 결과 창이 열리지 않음 | 잘못된 필드 복구 후 결과 창 표시. 유효한 다른 기록 유지 |
| 곡식 창고 저장 값 `step:99` 또는 `sorted:null` | 놀이 준비 실패, 재시도해도 같은 실패 | 단계·배열·선행 조건을 검증하여 실행 가능한 상태로 복구 |
| 오디오 재개가 늦는 동안 다시 일시정지 | 일시정지 창이 떠 있는데 레이싱 시간이 75초에서 74초로 감소 | 요청과 게임 인스턴스를 재확인. 같은 검사에서 75초 유지 |

추가로 완료 시 자동 체크포인트 타이머를 정리하여 완료 후 곡식 창고의 중간 저장이 다시 만들어지는 경로를 막았다. 이 항목은 코드 검토에서 확인한 문제이며 위 5건의 브라우저 재현과 구분한다.

## 실제 확인 범위

| 구분 | 실행 범위 |
| --- | --- |
| 배포 주소의 기존 버전 | 인증된 실제 배포 URL을 Chrome에서 열고 8개 도움 모드 완료, 일반 모드 1·6장, 완료 후 새로고침, 일시정지, 키보드 진입, 터치 입력 모사, 저장 실패 상황 검사 |
| 수정 소스의 로컬 HTTP 실행 | 기본 검사 재실행, 5개 오류 주입 재현의 수정 전·후 비교. 수정 후 5개 모두 통과 |
| 화면 크기 | 1024×768, 768×1024, 1366×768. 홈과 8개 초기 화면의 문서 스크롤·주요 버튼 잘림 검사. 1024×768에서 8개 도움 모드 결과 창까지 검사 |
| 일반 모드 | 1장 길 연결, 6장 분류·계량·자료 열람·비교·대화 완료. 4장 레이싱과 7장 리듬은 실제 시간 진행을 별도 검사 |

1024×768 이외 두 크기에서는 모든 게임의 완주를 반복하지 않았다. 실제 태블릿·크롬북 하드웨어, 손가락 조작, 스피커 출력·청감, 학생의 재미와 수업 효과는 미검증이다. 곡식 창고 이외 모든 놀이의 중간 상태 복원을 보장하는 검사가 아니다.

## 재현 자료

- `tests/browser-check.cjs`: 기본 플레이·배치 검사. `EMBEDDED_SERVER=1`로 같은 프로세스의 HTTP 서버 사용.
- `tests/regression-edge.cjs`: 손상 저장 4건과 지연 재개 1건. `EDGE_RESULT_NAME`으로 수정 전·후 JSON 구분.
- `tests/live-deployed-audit.cjs`: 기존 비공개 사이트 접근 권한을 숨김 표준입력으로만 받아 실제 배포 URL 검사. 자격 증명을 파일이나 로그에 저장하지 않음.
- 실행 로그·화면은 로컬 `test-results/`에 보존. 관찰 횟수는 독립 테스트 케이스 개수와 같지 않음.

## 최종 배포 및 재검사

수정 소스 `4ea0ecd021883e964c9a2ac13a4303f591703983`를 기존 비공개 사이트에 배포했으며 배포 상태는 `succeeded`다. 주소: https://joseon-memory-play.chlalsgh.chatgpt.site/ . 공개 범위는 변경하지 않았다.

배포 후 같은 URL에서 기본 검사를 다시 실행했다. 58개 관찰 기록에서 페이지 예외·콘솔 오류·HTTP 오류 0건, 검사한 화면의 문서 넘침·주요 버튼 잘림 0건이었다. 8개 도움 모드 완료, 일반 모드 1·6장, 완료 저장, 일시정지, 터치 입력 모사와 키보드 경로를 다시 통과했다.

배포 후 손상 저장 4건과 오디오 지연 재개 1건도 별도 브라우저 컨텍스트에서 다시 실행해 5건 모두 통과했다. 일반 모드 장시간 검사는 수정된 동일 소스의 로컬 HTTP 실행에서 레이싱 75초·기록 180, 리듬 약 63초·기록 332로 완료했다. 장시간 완주는 배포 URL에서 반복하지 않았다.

이는 실행한 경로의 결과이며 모든 조합에서 오류가 없다는 보증은 아니다. 기본 결과 JSON과 오류 주입 결과는 각각 `test-results/live-deployed/browser-results.json`, `test-results/live-deployed/edge-audit/results.json`이다.
