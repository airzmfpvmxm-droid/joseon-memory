# CH06 곡식 창고 독립 설계 검토

작업 ID: CH06-QA-DESIGN-001 / 담당: 05 UX·QA / 2026-11-18

## 범위와 증거 수준

운영 기준 v1.0과 공통 식별자를 기준으로 스토리·게임 규칙·아트/UI·음향의 사전 명세를 독립 검토한다. 이번 기록은 문서 검토다. 새 게임의 실행 가능한 구현, 브라우저 실조작, 실제 태블릿·크롬북 사용, 화면 크기 모사, 청취 검증은 수행하지 않았다. 아래 테스트는 구현 후 실행할 계획이며 통과 결과가 아니다.

검토 상태: 01·02·03·04의 v0.1 초안 독립 검토 → 수정 요청 → 각 작성자 수정 → 스토리·게이밍·아트 v0.3 및 사운드 v0.4 재검토 완료. 아래 6개 이슈 묶음은 문서상 보완되었다. 구현·실기 테스트 완료를 뜻하지 않는다.

## 구현 후 플레이 검사 계획

| 검사 | 경로와 관찰 | 완료 기준 |
|---|---|---|
| 첫 발견 | 새 저장에서 창고 진입, 안내 읽기, 주민 탐색 | 주민이 화면에 보이며 그림 자체를 선택할 수 있고 첫 목표가 명확함 |
| 사건 이해 | 농민의 첫 대화를 끝까지 읽음 | 빌린 양·약속된 상환·추가 요구·확인 위치가 구분됨 |
| 조사 순서 | 기록 먼저/곡식 먼저 두 경로 | 두 증거를 확인하기 전 비교 완료·보고 완료로 건너뛰지 않음 |
| 재방문·취소 | 대화, 자료창, 비교 도중 닫고 다시 열기 | 다음 행동을 다시 안내하며 이미 확인한 근거가 남음 |
| 오답 | 상환 이자 자체를 부정으로 선택, 숫자만 맞추고 근거 누락 | 이유를 설명하고 페널티 없이 재시도 가능, 잘못된 결론은 확정되지 않음 |
| 입력 | 마우스·키보드, 지원되는 터치 환경을 각각 조작 | 드래그 전용 동작 없음, 포커스 보임, Enter/Space 선택과 닫기·복귀 가능 |
| 결과 | 보고 전/후 같은 장면 비교 | 주민 표정·대사·목표의 변화가 저장 상태와 일치함 |
| 저장·재개 | 각 단계와 완료 후 새로고침·재진입 | 단계·근거·보고 여부가 일관되고 보상·완료 연출 중복 없음 |
| 저장 예외 | 저장 불가·이전 형식·손상 데이터 | 진행을 잃었다고 오인하지 않게 안내하고 새로 시작·복구 경로 제공 |
| 소리 | 첫 입력 전후, 음소거, 대화 중, 탭 전환 | 소리가 없어도 모든 단서 전달, 사용자 설정 유지, 중첩·갑작스러운 큰 소리 없음 |
| 이미지 누락 | 주민/필수 증거 자산 로드 실패 | 보이지 않는 클릭 대상만 남지 않고 오류·복구 안내가 있음 |
| 화면 | 각 목표 크기에서 전체 장면·겹창·비교·설정 확인 | 페이지 전체 스크롤·주요 UI 잘림 없음, 문서 페이지 전환 가능 |

화면 목표: 1366×768(크롬북 기준), 1024×768·1180×820(태블릿 가로), 768×1024(세로). 브라우저 화면 크기 모사와 실제 기기 결과는 별도 열로 기록한다. 목표 크기만 설정했다고 실제 기기 검증을 완료한 것으로 보고하지 않는다.

## 문제 분류와 인계

- P0: 진행 불가·저장 손실·필수 상호작용 접근 불가.
- P1: 주요 조작 오류·역사 학습 오해·필수 안내 누락.
- P2: 가독성·탐색·편의 문제.
- P3: 미관·선택적 연출 개선.

각 이슈는 관찰된 명세 내용, 예상 위험, 제안, 작성자 응답, 실제 수정 위치, 재검토 판정을 구분한다. 문서에서 해결되면 ‘설계 보완’으로만 기록하며 구현 통과로 승격하지 않는다.

## 최종 인계와 남은 확인

- 문서 재검토 대상: story/ch06-warehouse.md v0.3, gameplay/ch06-warehouse.md v0.3, art-ui/ch06-warehouse.md v0.3, audio/ch06-warehouse.md v0.4. 추가로 신규 저장소의 docs/gameplay/ch06-integration.md 총괄 결정 v0.1(운영 v1.1)을 읽어 INT-001~003과 대조했다.
- 문서상 보완: 이슈 6개 묶음. 중간 위치 결정 충돌도 최종 INT-001 전달 후 재검토했다.
- 통합 계약 대조: INT-001의 공간·소유, INT-002의 가상 수치·표본 증거 범위, INT-003의 상태·저장 분리를 작성자 수정본과 대조했다. audio v0.4는 문서 열기 이벤트를 `ui_document_opened {objectId}` 하나로 통일하고 이전 개별 opened 이벤트 동시 발행을 폐기했다. 구현에서는 실제 자산·저장 스키마·이벤트 발행부에도 동일 계약을 반영해야 한다.
- 표본 조사를 필수로 둔 것은 수량 계산에 필요해서가 아니라 주민의 곡식 상태 고충을 확인하는 별도 목적이다. 보고 대사에서도 이를 다루고 표본 단독으로 봄 지급 상태나 전체 양을 입증하지 않게 유지한다.
- 이후 실제 플레이 검증에서 확인할 핵심: 농민 첫 발견, 쪽지의 농민 대화/자료 열람 경로, 3자료 순서 바꾸기, 저장 실패 중 완료·이탈, 작은 표본 터치 영역, 겹창 초점 순환, 늦게 끝난 음원 요청 취소.
- 현재 판정: **다음 단계 인터페이스 확정에 사용할 수 있는 사전 명세**. 구현 품질·학습 효과·실제 기기 사용성은 미판정.
- 다음 인계: 00 총괄. 구현 완료 후 CH06-007 실제 플레이 검증을 별도 발행한다.
