## 범위와 증거 수준

대상은 04 게이밍의 `docs/gameplay/CASUAL-MINIGAMES.md`다. 최초 초안 수신 전 아래 독립 평가 기준을 먼저 작성했다. 이 기록은 기획 문서 검토이며 게임 구현·브라우저 실조작·실제 태블릿·키보드·터치·음향 지연·학생 재미 검증 결과가 아니다.

‘재미가 있다’는 문서만으로 확정하지 않는다. 설계상 놀이의 구조가 존재하는지 판단한 뒤 실제 학생 플레이에서 재미·피로·이해를 검증한다.

## 장별 설계 판정 — 최초 초안

| 장 | 놀이 구조와 차이 | 최초 판정·수정/실기 확인점 |
|---|---|---|
| 1 길 회전 | 방향·연결 관계를 예측하고 수레 이동으로 확인 | 회전 퍼즐 성립. UI의 선택→배치와 동기화 필요 |
| 2 글자 공방 | 자모 위치·음절 조립·짧은 요청 처리 | 조립 루프는 있으나 정답 위치 매칭에 머무는 위험. 요청 처리 기술 차이 보완 요청 |
| 3 지붕 수리 | 조각 회전·빈 공간·겹침 없는 채움 | 공간 퍼즐 방향은 타당. CH02와의 차이 및 여러 배치·되돌리기 명료화 요청 |
| 4 안전 보급길 | 차선 예측·장애 회피·운반 경로 | 레이싱/러너의 기술이 분명. 도달 불가능 배치·재개 유예 검증 필요 |
| 5 돌수레 | 기울기 감쇠·속도·멈춤의 균형 조절 | 레이싱과 구분되는 지속 제어. 한 번 탭 유지·정지 단계 대안을 실제 검증해야 함 |
| 6 곡식 관찰·계량 | 관찰 분류와 양 조절·초과 복구 | 행동 요소는 있으나 분류를 단순 정답 문제로 제한하지 말고 계량 피드백·조절감을 실기 확인. 과거 피해 증거와 연습 분리는 적절 |
| 7 합주 | 박자 예측·쉼·두 입력의 타이밍 | 기술과 재도전 목표가 분명. 무입력 완료·모드·지연·중단 롤백 계약 보완 요청 |
| 8 천리경 | 시야·확대·형태 관찰·대상 찾기 | 정밀 숨은 픽셀 찾기보다 관찰·탐색 방향. 정적/후보 선택 대안에도 같은 발견 대사 제공 확인 |

세 장이 배치 엔진을 공유하는 것 자체는 결함이 아니다. 길 연결, 음절 조합, 공간 채움의 규칙과 판단이 실제로 다르게 구현되는지 후속 플레이에서 확인해야 한다.

## 구현 후 확인 계획

- 8장 각각 연습·기본·쉬움/접근성·대체 참여 경로를 플레이한다.
- 마우스, 키보드, 실제 터치 검증은 따로 기록하고 화면 크기 모사만으로 실제 태블릿 통과로 보고하지 않는다.
- 목표 화면: 1366×768, 1024×768, 1180×820, 768×1024. 배율·브라우저 UI·안전 영역·글자 확대를 포함한다.
- 첫 실패·반복 실패·중단·완료·저장 실패·새로고침·탭 숨김/복귀를 각각 검사한다.
- 리듬은 장치 지연과 무음, 레이스는 저프레임·대체 입력과 난도 차이, 정밀 조작은 단일 탭 대안을 검사한다.
- 점수·장식 보상과 필수 단서·주민 대사·다음 챕터 접근을 분리해 검증한다.
