# 독립 검토와 인계 절차

운영 v1.1 / 2026-11-18

## 실행 구성
- 총괄: root. 작업 발행, 충돌 조정, 문서 통합과 공개 저장소 반영.
- story: 스토리와 역사 검토 초안.
- gameplay: 플레이 규칙 독립 설계 후 스토리와 교차검토.
- art_ui: 화면·자산·상태 표현 설계와 입력 영역 검토.
- audio: 사운드와 진행 이벤트 연결 검토.
- ux_qa: 초안 독립 검토, 작성자에 수정 요청, 수정 후 재확인.

## 검토 증거
각 검토는 대상 문서·버전, 발견한 문제, 수정 제안, 작성자의 처리, 재확인 결과를 기록한다. 문서만 읽은 검토는 설계 검토이며 실제 플레이 테스트가 아니다. 테스트할 코드·음원·이미지가 없으면 해당 검증을 미실시로 표시한다.

## 파일 관리
담당별 작성 파일을 분리한다. 이번 사이클의 초안 작업 경로는 기존 작업 폴더 deployrepo/docs 아래이며, 총괄이 결과만 joseon-memory/docs로 통합한다. 기존 게임 코드와 원격 저장소에는 변경을 보내지 않는다.

## 실행 시간
에이전트는 현재 요청 처리 동안 실행된다. 다음 사용자 요청에서는 HANDOFF.md를 기준으로 작업을 재개한다. 문서 게시를 에이전트의 지속 실행이나 자동 대화 공유로 표현하지 않는다.
