# 길 연결 퍼즐 시인성 수정

2026-11-20. 학생이 출발·도착 위치를 식별하기 어렵다는 사용자 피드백에 따른 수정.

- 판 위의 양쪽 문구를 제거했다. 실제 왼쪽 위 칸에 초록색 ‘출발·목수’, 오른쪽 아래 칸에 파란색 ‘도착·경복궁/장터/나루터’를 붙였다.
- 시작과 도착은 고정했다. 누르면 해당 칸의 역할을 설명하며 회전하지 않는다.
- ‘왼쪽 위 출발에서 오른쪽 아래 도착까지’라는 위치 안내를 제공한다.
- 옅은 바탕과 밝은 길, 짙은 길 테두리로 대비를 높였다. 출발지와 연결된 길은 초록색으로 표시한다.
- 글자와 위치로도 두 지점을 구별하므로 색에만 의존하지 않는다.

Chrome에서 1024×768, 768×1024, 1366×768의 화면과 도움 모드 3라운드 완료를 확인했다. 스크롤·주요 버튼 잘림은 관찰되지 않았다. 실제 화면 캡처를 육안으로 확인했다. 학생 대상 이해도 검사는 아직 하지 않았으며, 기계적인 완료 검사를 학생의 이해도 검증으로 해석하지 않는다.
