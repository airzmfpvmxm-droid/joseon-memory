# 기획 세션 검토·제작 지시 — 2026-11-23

## 판정과 근거
현재 버전은 따뜻한 삽화의 방향은 맞지만, 참고작을 연상시키는 탐험 화면과 대화 연출은 부족하다. 임무 설명·조작법·학습 정리가 장면보다 앞에 나와 학습 웹페이지 인상이 남는다. 그래픽/UI와 게임성 검토를 독립 수행했다. 아래는 확정 제작 지시이며 완료 보고가 아니다.

검토 자료: 현재 소스와 로컬 Chrome 1024×768의 2장 탐험·대화 화면, 실제 로딩 폰트와 WOFF name table, 배급사 공식 소개 및 Steam 공개 이미지. 지정 YouTube 영상 W1pk6SokvWs는 직접 재생 확인하지 못했다. 영상 전체·원작 대화 UI·모션 타이밍까지 검증했다고 주장하지 않는다. 정량 유사도 백분율은 부여하지 않는다. 제작 기준 수치는 우리 프로젝트의 합격 기준이다.

## 2 그래픽·UI 세션 지시
- ART-01 / P0: 상하 고정 안내와 갈색 여백을 줄이고 풍경을 중심에 둔다. 장소·당장 할 일·메뉴는 작은 겹침 UI로 전환. 가로 풍경 표시 면적65% 이상 목표. 세로는 억지 확대·왜곡 대신 안전 영역과 배치로 대응. 배경 자르기·축척 변환은 인물·클릭 좌표에 동일 적용한다.
- ART-02 / P0: 대화 때 탐험 장면과 두 인물의 발 위치를 유지한다. 현재 story-flow.js에서 별도 배경 화면으로 갈아끼우는 구조를 수정한다. 대화창은 얼굴을 가리지 않게 하단에 겹침. 컷신 제외. 표정2종·작은 손짓은 실제 자산과 연결한 뒤 완료로 인정.
- ART-03 / P0: 본문용 둥글고 획이 분명한 한글 글꼴 하나를 직접 포함한다. 파일 실명·라이선스·배포 포함 여부를 기록한다. 원작과 같은 글꼴이라고 추정하지 않는다. 대사20~22px, 이름/버튼16~18px, 보조14px 이상, 대비4.5:1 이상. 모든 장 한글·숫자·문장부호와 Chromebook fallback 확인.
- ART-04 / P1: 상시 사각 명찰을 없애고 접근/선택 시 실제 이름(복이 등)을 표시. 투명 터치44px 유지. 발밑 접지·빛·외곽선·원근·앞뒤 순서를 장별 점검.
- ART-05 / P1: 일반 대사의 기본 행동1개, 보조 메뉴 진입1개 이하. 큰 장 제목 카드는 장소·시대 라벨로 축소. 가로 대화창 높이28% 이내 목표. 긴 대사는 작게 줄이지 말고 발화 단위로 분리.

## 4 게이밍·1 스토리 세션 지시
- PLAY-01 / P0: app.js 완료창의 ch.after 역사 정리와 ch.detail 고증 설명을 그림첩 ‘더 알아보기’로 이동. 핵심 학습 자료를 삭제하지 않는다. 필수 흐름은 주민 반응→현재 장면의 변화→다음 행동으로 연결. 기록·점수는 선택 열람.
- PLAY-02 / P0: acceptLabel, questLine, resultReaction을 장 데이터로 관리. 공통 ‘놀이 시작’ 대신 실제 행동을 명명. 아직 없는 앉기·손잡이 애니메이션을 구현한 것처럼 약속하지 않는다.
- PLAY-03 / P1: 최초 조작 안내는 한 번만 짧게, 이후 도움말에서 다시 열기. 모든 장 상하단의 같은 지시를 반복하지 않는다. 당장 필요한 힌트는 막혔을 때 단계별로 제공.
- PLAY-04 / P1: ‘정답이 정해진 선택은 아니에요’를 매번 읽히지 않는다. 실제 두 선택에 다른 유효 반응을 연결. 기록은 ‘이 장에 무엇을 남길까?’, 질문은 ‘무엇이 궁금하니?’로 시작.
- PLAY-05 / P1: 주요 장면마다 서로 다른 경로의 선택 관찰물2개 이상, 생활을 보여 주는 짧은 반응 추가. 단순 아이콘 추가 금지. 장면별 실제 바닥·장애물로 이동 영역 정의. 플레이 결과는 자루·수레·종이 등 지속 상태로 드러내기. 역사적 문제 전체 해결로 과장하지 않기.

## 제작 순서·완료 게이트
1. 2장 한 장면에서 ART-01~03, PLAY-01~03 시범 구현 후 실제 화면 비교. 전체 그림을 다시 만들기 전에 구도·글꼴·대화 구조를 확정.
2. 총괄 승인한 구도를 8장 확장. UI와 이야기 진행 조건·저장을 분리하지 말고 함께 검증.
3. UX/QA: 1024×768·768×1024·1366×768, 페이지 스크롤0, 클릭/터치/키보드, 인물 접지·대화 전후 위치 유지·얼굴 가림·한글 누락·저장/재시작 회귀 검사.
4. 학생이 역사 해설 모달을 먼저 읽지 않아도 어디서 무엇을 할지 발견 가능한지 첫 사용 관찰. 안내 없이 발견하지 못하는 지점과 힌트 요청을 기록. 교사가 느끼는 분위기와 학생이 실제 찾는 능력을 구분.

- 확인 완료: 위 자료·소스·로컬 Chrome 대표 화면과 폰트 파일.
- 지시 완료: 본 문서의 ART/PLAY 작업 정의·우선순위·완료 기준.
- 미구현: 이번 검토에서 게임 코드·그래픽·음원을 변경하지 않았다. 외형이 참고작 수준에 도달했다고 판정하지 않는다.
- 미확인: 지정 영상 전체, 원작 정확한 서체·대화 UI·프레임 타이밍, 8장 신규 전수 플레이와 실제 학생 사용자 시험.
