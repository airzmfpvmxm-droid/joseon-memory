# 플레이 버전 자산

2026-11-19

- assets/scene-*.webp: 이 대화에서 기존 조선 마을 게임용으로 제작했던 배경 일러스트를 재사용·분할·크기 조정했다. 새 게임의 각 역사 장소를 정밀 복원한 자료 사진이 아니라 이야기 놀이의 배경이다.
- assets/farmer.webp: 앞서 제작한 피해 농민 스프라이트 재사용.
- assets/village.woff: 기존 게임에 포함된 표시용 글꼴 재사용. 본문은 기기의 한글 시스템 글꼴로 표시한다.
- 길 조각·지붕 조각·수레·곡식·북·천리경 풍경은 게임 모듈의 독자적인 SVG/CSS로 제작했다. 참고 게임의 이미지·음악·캐릭터를 복제하지 않았다.
- 사운드는 Web Audio로 직접 합성한 짧은 효과음과 창작 박자다. 실제 전통 음악의 고증 재현·녹음이 아니다.
- 캐릭터의 손짓·배경의 작은 동작과 게임 오브젝트 움직임으로 진행하며 컷신 영상은 사용하지 않는다.

실제 태블릿 사용성·학생의 재미·교육 효과는 별도 확인이 필요하다. 새 플레이 버전과 이전 joseon-village 게임은 별도 저장소·저장 데이터를 사용한다.
