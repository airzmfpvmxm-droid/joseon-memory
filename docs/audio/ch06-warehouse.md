## 1. 장면 의도

곡식 창고는 주민의 어려움을 차분하게 듣고 실물과 기록을 살피는 곳이다. 입장 시 작은 바람과 나무의 기척으로 공간을 알리고, 학생이 곡식을 실제로 다룰 때만 곡식 소리가 난다. 말소리·과장된 비탄·공포 음향·승리 팡파르는 넣지 않는다. 피해 농민의 사연을 보상 연출의 소재로 소비하지 않는다.

배경음악은 정서의 보조다. 최초 시범 구간에는 환경음과 필요한 효과음부터 적용하고, 음악이 대사 읽기를 방해하지 않는지 확인한 뒤 최소 편성의 독자 곡을 추가한다. 악기 선택은 정확한 역사 고증을 주장하지 않는 창작 음향으로 기록한다.

## 2. 버스·초기 음량

수치는 구현을 위한 출발값이며 실제 기기 청취 후 확정한다. 원본 음원의 크기가 제각각인 상태에서 게인 수치만으로 음량 균형을 보장하지 않는다. 제출 음원마다 피크와 통합 음량 측정값을 기록하고 최종 출력 클리핑을 검사한다.

| 버스 | 초기 선형 게인 | 사용자 설정 | 원칙 |
|---|---:|---|---|
| master | 0.65 | 전체 음소거·전체 음량 | 갑작스러운 큰 소리를 피한다 |
| music | 0.16 | 음악 음량 | 환경음보다 존재감이 크지 않게 시작 |
| ambience | 0.28 | 환경음 음량 | 긴 무음 구간을 허용한다 |
| sfx | 0.45 | 효과음 음량 | 물건을 다루는 순간만 명확히 |

- 대화창이 열리면 music을 현재 설정의 40%, ambience를 65%로 180ms 동안 낮춘다. 닫힐 때 350ms에 걸쳐 원래 값으로 복귀한다.
- 같은 대화 안에서 페이지가 바뀔 때는 낮춤/복귀를 반복하지 않는다. 문서 조사 겹창도 대화와 같은 집중 상태로 처리한다.
- 사용자 음량은 상한이며, 자동 낮춤을 해제할 때 음소거·0 음량을 덮어쓰지 않는다.
- 음향을 모두 꺼도 목표·힌트·정오 판단·완료 여부가 글과 시각 상태로 전달되어야 한다.

## 5. 중복·우선순위·오류 처리

- 음악 1개, 환경음 1개만 활성화한다. 효과음은 최대 2개로 제한한다.
- 우선순위는 실제 물체 조작 > 완료 확인 > 보조 UI 효과음이다. 사용자 입력을 소리 재생을 기다리게 하지 않는다.
- 동일 물체를 연속 클릭할 때 첫 재생을 처음부터 반복해 잘라먹지 않는다. 허용 간격 전 요청은 무시한다.
- 반짝임·hover·키보드 초점 이동·타자 출력 글자마다 소리를 넣지 않는다. 필요한 정보가 소리에만 의존하지 않게 한다.
- 음원 로드/디코딩/재생 실패는 비치명적 오류로 기록하고 게임 진행은 계속한다. 예외를 대화나 미션 흐름으로 전파하지 않는다.
- 개발 중 누락 자산은 검사 목록에 표시한다. 사용자 화면에서 이모지나 경고 팝업으로 대체하지 않는다.

## 6. 브라우저 재생·설정·저장

- AudioContext 또는 미디어 재생은 최초 명시적 사용자 입력 이후 시작한다. 정책 때문에 실패하면 소리 없이 계속하고, 화면의 음향 켜기 조작에서 다시 시도한다.
- 음향 설정 저장 키 제안: joseon_memory.audio.v1. 데이터: muted, master, music, ambience, sfx. 모두 범위를 검증하고 손상·차단 시 기본값을 사용한다. 진행 저장과 분리한다.
- 음소거 해제는 브라우저가 허용하는 사용자 입력 경로에서 실행한다. 사용자의 이전 음량을 보존하고 강제로 볼륨을 높이지 않는다.
- 탭이 숨겨지면 음악·환경음은 멈추거나 suspend하고 효과음은 중지한다. 그동안 대기한 소리를 모아 재생하지 않는다.
- 비동기 로드·디코딩·AudioContext.resume 요청에는 장면 세대 ID와 취소 토큰을 부여한다. 장면 이탈·탭 숨김·음소거·재생 세션 교체 때 이전 요청을 무효화한다. 취소할 수 없는 디코딩이 늦게 끝나도 자산 캐시에만 보관하며 재생하지 않는다.
- 실제 play 직전에 요청의 세대 ID, 현재 장면 ID, 탭 가시성, 사용자 음소거, 해당 버스의 0 음량 여부, 입력 후 재생 허용 여부를 재검증한다. 불일치 요청은 폐기한다. 예전 resume 완료 콜백으로 재생이 다시 시작되지 않게 하고, 재입장 재생은 새 요청으로만 시작한다.
- 돌아왔을 때 현재 장면과 음소거 설정을 다시 확인한다. 허용되는 경우만 잔잔하게 이어 재생하고, 정책이 차단하면 다음 명시적 입력까지 기다린다.
- 저장 후 새로고침해도 완료음·종이 펼침 소리가 자동 재생되지 않는다. 소리 재생 여부는 학습 완료 저장 플래그와 분리한 현재 세션 상태로 관리한다.

## 7. 제작·권리 메타데이터

자산 ID, 파일, 생성/획득 방식, 제작자, 출처, 사용 허가, 편집 내역, 길이, 표본화 정보, 피크·음량 측정값, 루프 시작·종료, 버전, 파일 크기를 제출한다. 참고작 음원·영상에서 추출한 소리를 사용하지 않는다. 일반적인 의성어나 조선 풍의 악기라는 설명만으로 역사적 재현성을 주장하지 않는다.

## 8. 검증 계획과 현재 한계

현재 확인한 것은 공통 운영 문서와 ID 명세뿐이다. 실제 음원이 없으므로 청취·자동 재생·탭 전환·루프·클리핑·기기별 음량은 모두 미검증이다.

| 검사 | 기대 결과 |
|---|---|
| 첫 진입·최초 입력 전후 | 콘솔 예외 없이 무음 진입, 허용 입력 후만 재생 |
| 대화·자료 창 열고 닫기 | 읽는 동안 음향 감소, 창이 겹칠 때도 갑작스러운 복귀 없음 |
| 물체 빠른 연속 클릭 | 효과음 폭주·진행 중단 없음 |
| 음소거 상태로 모든 활동 | 의미 전달·임무 완료에 손실 없음 |
| 새로고침·완료 상태 복원 | 설정 유지, 과거 완료음 재생 없음 |
| 숨긴 탭에서 복귀 | 누적 효과음 재생 없음, 중복 환경음 없음 |
| 로드·디코딩·resume 지연 중 음소거/장면이탈/탭숨김 | 늦게 완료된 이전 요청은 재생되지 않음. 복귀·재입장 때 새 요청만 허용 |
| 태블릿·크롬북 스피커/헤드폰 | 대사가 읽기 어렵거나 소리가 갑자기 커지는 구간 없음 |
| 음원 한 개 누락·네트워크 지연 | 게임 계속 진행, 개발 오류만 기록 |

실제 기기 청취와 브라우저 화면 크기 모사는 다르다. QA는 기기·브라우저·출력 장치·음량 설정·구간을 기록해야 한다.

## 9. 교차 검토 기록
