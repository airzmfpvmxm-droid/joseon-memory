## 1. 공통 플레이 계약

### 진행과 보상의 분리
- 각 장의 미니게임 첫 회는 60~120초의 짧은 도전이다. 첫 10초 안에 짧은 시범과 한 번의 직접 조작을 제공한다. 설명을 다 읽을 때까지 시간은 흐르지 않는다.
- 타이머 종료·실수·낮은 점수는 교과 진행 실패가 아니다. 언제든 일시정지 창에서 '함께 해 보기', '시간 없이 해 보기', '차근차근 완료하기'를 선택한다. 강제 재도전·실패 횟수 제한·목숨·필수 속도 점수는 없다. 활동 도중 '이야기 계속' 버튼은 표시하지 않는다.
- '차근차근 완료하기'는 결과 숫자만 보여 주는 정답 건너뛰기가 아니다. 해당 장의 핵심 장면을 1단계씩 직접 조작하며 확인하는 비시간 협력 경로다. 도우미가 시범을 보이고 플레이어는 경로 한 구간 잇기·표본 확대·근거 열기 등 필수 관찰/읽기/선택을 수행한다. 잘못 고르면 관련 부분을 보여 준 뒤 다시 선택할 대상을 명확히 알려 주어 무한 추측을 요구하지 않는다. 필수 동작 확인 후 assistedCompleted가 되고, completed와 동일한 결과 화면에서만 '이야기 계속'을 표시한다.
- 이야기용 발견·주민 대사·마을 그림 복원·진행 보상은 모든 경로에서 동일하다. 자발적인 추가 도전은 개인 최고점·장식용 기록 도장만 제공한다. 교과서 자료·스토리·필수 아이템을 점수로 잠그지 않는다. 순위표·시간 경쟁은 강제하지 않는다.
- 접근성 설정에 따른 점수 차이를 능력 등급으로 표현하지 않는다. 기록은 같은 설정끼리만 개인 갱신하며 '기본/느긋한/협력' 규칙을 표시한다. 보조 모드도 장식 선택권은 같다. 무시간·자동보조에서 기본 기록을 덮어쓰지 않는다.

### 입력·한 화면·중단
- 기본 입력은 탭/클릭과 키보드로 완결한다. 드래그·기기 기울이기·소리 듣기·색 구별만을 필수로 하지 않는다. 상호작용 항목은 44×44 CSS px 이상을 목표로 하고 캔버스 내부 항목도 초점·이름·선택 표시를 제공한다.
- 공통 키: Tab/Shift+Tab 이동, Enter/Space 선택, Esc 일시정지/닫기. 방향키 사용 게임은 시작 전에 안내하고, 문서·겹창 열림 동안 게임 입력을 중지한다. Space는 페이지 스크롤을 유발하지 않는다.
- 태블릿 가로1024×768, 세로768×1024, 크롬북1366×768을 초기 화면 목표로 한다. 전체 페이지 스크롤 없이 장면·최소 HUD·조작 영역을 한 화면에 둔다. 레이싱·균형·리듬은 상단 활동영역과 하단 조작바를 고정 분리하며 좌우 입력은 각64px 이상을 초기 목표로 한다. 조각 팔레트는 작게 줄이지 않고 4개씩 순환/쪽전환한다. 화면 회전·탭 전환·브라우저 비활성·설명·자료창·연결된 대화창 진입 시 타이머와 음악 시계를 함께 일시정지한다. 결과는 하단바/겹창에서 직접 다음을 눌러 닫는다.
- 그림과 클릭 영역은 같은 좌표계에서 스케일링한다. 작은 오브젝트를 찾는 게임도 읽을 수 없는 크기로 축소하지 않는다. 움직임 줄이기는 화면 흔들림·점멸·빠른 자동 스크롤을 끄고, 정적인 대체 화면을 제공한다.
- 저장: chapterId, minigameId, rulesVersion, accessibilityPreset, 학습확인 flag, storyComplete, draft/checkpoint, 개인 기록을 구분한다. 저장 실패는 세션 내 완료·다음 장을 막지 않으며 보존 실패와 재시도를 알린다. 재개는 각 장의 안전 체크포인트에서 한다. 리듬·레이싱 중 프레임/일시적 효과음은 영속 저장하지 않는다.
- 결과 화면에는 '잘한 점 한 가지 + 이야기와의 연결 한 문장 + 다시 도전/다음 이야기'를 둔다. 벌점음·고통 연출·동료 비난을 넣지 않는다.

## 3. CH01 — 한양, 길을 이어 주세요

- 연결 이야기: 새 도읍에 온 목수가 길을 몰라 도움을 청한다. 고정된 궁궐·성문·거리 사이의 짧은 동선을 연결한다. 유교·건국 대화는 별도로 유지한다.
- 실제 조작: 단순화한 4×4 지도판에서 길 조각을 탭해 90도 회전한다. 키보드는 방향키로 칸 이동, Enter 회전. 출발·도착 명소는 움직이지 않는다. 길 연결 후 수레가 짧게 지나가 결과를 보여 준다.
- 규칙/목표: 막힌 길·물길을 피하고 출발점부터 표시된 목적지까지 이어진 도로를 만든다. 처음에는2개, 다음에는3개 조각 회전으로 완성하도록 난도를 올린다. 최대3개 작은 판을90초 안에 연결한다. 역사적 장소를 마음대로 재배치하는 게임으로 만들지 않는다.
- 성공/재시도: 연결이 이어지면 해당 구간 성공. 잘못 회전해도 즉시 다시 회전 가능, 시도 횟수 감점 없음. 시간 종료 시 현재 연결을 유지한 채 계속/협력/재도전 선택. 선택 도전 점수는 완성 수+남은 시간이며 필수 보상과 분리한다.
- 협력 확인: 도우미가 다음 길 하나를 보여 주고 플레이어가 한 조각 연결한다. 수레가 도착한 곳을 살펴보고 그 장소의 역할을 듣는다. 나머지는 함께 완성한다.
- 보조: 무시간, 다음 칸 방향 고정 표시, 회전 대신 후보 방향2개 선택, 이동 애니메이션 생략. 지도의 북쪽·물길·랜드마크 위치는 01 검토한 단순화 배치 사용. 경복궁·종묘·사직단·성문은 고정하고 길 조각만 회전한다. 이 판을 실제 정밀 한양 지도라 설명하지 않는다.
- 보상/변화: 목수와 수레가 목적지에 남고 마을 그림에 길이 복원된다. 자산: 도로 직선/굽이/막힘 타일, 단순화 지도, 수레2방향, 고정 명소3개. eng_tileboard.route는 후속 마을 길 퍼즐에 재사용 가능.

## 4. CH02 — 글자 공방의 첫 부탁

- 연결 이야기: 자기 말을 글로 남기고 싶은 주민이 짧은 부탁을 한다. 먼저 훈민정음을 만든 까닭과 배우기 시작하는 사람의 이야기를 듣고, 별도의 글자 놀이판을 연다.
- 실제 조작: 소리와 그림으로 제시된 '나무·바다·나라' 등 친숙한 현대 표기 단어를 보고 자모 조각을 음절칸에 놓는다. 탭은 조각 선택→칸 선택, 키보드는 초점 선택→Enter→목적칸 Enter. 마우스 드래그는 선택 기능이다.
- 규칙/목표: 첫 연습은 초성·중성2조각의 한 음절 '나'다. 이후 나무·바다·나라 등 두 음절 요청으로 확장한다. 요청 단어3개를75초 안에 조립한다. 단어 목록과 표기는 교사 검토 후 확정한다. 소리를 못 들어도 그림·글자 안내로 동일 진행한다.
- 성공/재시도: 한 음절이 맞으면 조합과 읽는 소리를 짧게 확인한다. 다른 칸은 제자리로 돌려보내거나 다시 선택 가능, 재료 소모 없음. 시간 종료 후 계속/협력/재도전. 같은 글자를 반복 탭해 속도만 높이는 규칙은 넣지 않는다.
- 협력 확인: 주민이 전하고 싶은 말을 듣고 완성 음절의 자모가 합쳐지는 모습을 한 단계 관찰·선택한다. 틀려도 안내 후 조립이 이어진다. 이후 주민이 배움을 시작하는 대화로 복귀한다.
- 보조: 무시간, 현재 음절만 표시, 후보 수 줄이기, 글자 확대, 시범 조립, 듣기 선택적. 음절 조각의 장식이 글자 획을 가리지 않는다.
- 역사 경계: 이 활동은 학생이 이미 쓰는 현대 한글의 조립 놀이이며 훈민정음 창제 과정·제자 원리·당시 철자를 정확히 재현하는 게임이 아니다. 주인공이 글자를 발명했다거나 자모 조각 맞추기로 창제 원리를 모두 배웠다고 말하지 않는다.
- 보상/변화: 주민이 자기 이름을 한 글자씩 써 보기 시작하고 공방에 완성 연습지가 남는다. 자산: 선명한 자모·음절칸·부탁그림·연습지, 손동작2개. eng_tileboard.assembly의 문자 배치 검증기를 사용한다.

## 5. CH03 — 이웃집 지붕을 함께 고쳐요

- 연결 이야기: 향약의 어려운 이웃 돕기 장면. 어른들과 주민이 수리하고 플레이어는 안전한 조립 작업대에서 지붕 모형의 짚단 배치를 돕는다. 어린 주인공이 실제 높은 지붕에서 위험 작업을 하지 않는다.
- 실제 조작: 크기와 방향이 다른 지붕 조각6개를 윤곽에 맞춘다. 선택→대상 자리→놓기, 회전 버튼 또는 R로 방향 조정. 색 외에 짚결·홈·모양이 맞음의 단서가 된다.
- 규칙/목표: 겹침 없이 틈을 채우고 물이 흐를 방향을 맞춘다.90초, 첫2조각은 쉽게 맞는 모양. 남은 조각이 들어갈 공간을 생각하는 짧은 퍼즐로 만든다. 조각 배치가 실제 조선 건축의 전 공정을 재현한다는 설명은 하지 않는다.
- 성공/재시도: 완성되면 어른들이 해당 배치를 따라 지붕을 고치고 빗물이 밖으로 흐른다. 잘못 놓인 조각은 되돌릴 수 있고 건물 파손·주민 피해 없음. 시간 종료 시 진행 유지.
- 협력 확인: 도우미가 한 틈을 표시하고 플레이어가 조각 한 개를 직접 놓은 뒤, 주민이 왜 이웃을 돕는지 이야기한다. 다른 신분의 생활과 제약을 다룬 기존 대화는 그대로 남긴다. 지붕 수리 성공을 신분 차별의 해소·모두 평등 결말로 연결하지 않는다.
- 보조: 자동 방향 맞춤, 윤곽 대비, 후보 자리 표시, 무시간. 초점 이동 순서와 조각 순서 동일. 아이/여성/노비에게만 심부름을 고정 배정하지 않는다.
- 보상/변화: 수리된 지붕과 도와준 주민들의 모습이 남고 그림에 공동 작업이 복원된다. 자산: 수리 전후 지붕,6조각,작업대,물흐름 소규모 반복,주민수리 동작. eng_tileboard.assembly의 회전/맞물림 변형을 사용한다.

## 6. CH04 — 안전한 보급길

- 연결 이야기: 임진왜란 때의 한 가상 보급 장면. 주민 통행길과 분리하여 이미 확보한 안전한 운반길에서 물·식량을 전달한다. 전쟁 승패·피란민의 생존을 플레이어 점수에 걸지 않는다. 병자호란은 이후 별도 시대 장면에서 다루며 두 전쟁을 한 코스로 합치지 않는다. 전쟁 뒤 가족·주거 변화 대화도 유지한다.
- 실제 조작: 길이 자동으로 앞으로 움직이고 수레는3레인 중 하나에 있다. 화면 좌/우 큰 조작영역 또는 ←/→/A/D로 한 레인씩 이동한다. 위협 인물·무기·적 추격은 등장하지 않는다.
- 규칙/목표:75초/가상길450단위의 짧은 코스(초기값). 웅덩이·나뭇가지를 피하고 정해진 안전 지점의 보급 묶음을 수거한다. 장애물은 연속 레인변경을 요구하지 않으며 피할 수 없는 배치를 생성하지 않는다. 최소 사전 예고1.5초, 입력 후 레인전환0.25초는 초기값이다. 위험 예고는 시각 표시가 필수이며 소리에만 의존하지 않는다.
- 성공/재시도: 종점 도달이 기본 성공. 부딪히면 수레가 잠깐 천천히 가며 묶음 하나가 안전하게 길 가장자리로 놓이고 동행이 줍는다. 식량 영구 소실·부상·사망·게임오버 없음. 운반량은 추가도전 기록이며 낮아도 주민은 필요한 물자를 함께 받는다. 재시도는 첫/중간 체크포인트 선택.
- 협력 확인: 정지 화면에서 플레이어가 다음 안전 차선을 직접 선택하고 보급품의 쓰임을 확인한다. 나머지는 도우미의 느린 자동운전으로 종점까지 함께 간다. 피란민을 앞질러 경쟁하는 묘사는 넣지 않는다. 일시정지 후 레이싱은 정지 상태에서 다시 출발하고 숨겨진 시간의 장애물·충돌을 몰아 적용하지 않는다.
- 보조: 속도50%, 장애물 적게, 자동 회피, 정지 화면에서 다음 레인 선택, 배경 스크롤/흔들림 끄기. 좌우버튼을 못 쓰면 차선3개를 직접 탭하는 동등 입력도 제공한다.
- 보상/변화: 목적지에 물동이·곡식이 내려지고 주민의 안부 대화와 그림복원으로 이어진다. 자산: 안전길 타일, 수레·보급품,웅덩이/나뭇가지,도착공간. eng_runner3는 이후 평시 장터 배송에 재사용하며 전쟁 장면용 점수문구는 분리한다.

## 7. CH05 — 화성 돌수레, 천천히 힘을 모아

- 연결 이야기: 정조 때 수원 화성 공사 장면의 작은 운반 지원. 영조 때 탕평 설명에서 시대 전환을 표시하고 정조 때로 이동한다. 규장각·탕평·세도정치의 역사 대화는 별도이며 물리적 균형을 정치적 공정성과 동일시하지 않는다.
- 실제 조작: 고정 옆모습에서 수레의 무게중심과 짧은 경사길을 본다. 좌/우 힘 버튼을 누르거나 ←/→로 기울기를 조절하고, 멈춤 버튼/Space로 속도를 낮춘다. 자이로센서/기기기울임 필수 없음.
- 규칙/목표:90초 안에 경사3구간을 천천히 운반. 기울기 위험구간은 모양·텍스트·색으로 함께 표시. 한 번에0.5~1초 보정 입력이면 대응 가능한 완만한 초기값으로 설계한다. 힘이 갑자기 튀지 않게 감쇠를 둔다.
- 성공/재시도: 종점에서 돌을 내려놓으면 기본 성공. 넘어질 만큼 기울면 동행 일꾼이 수레를 멈추고 마지막 평지에서 다시 출발한다. 사람 깔림·돌 파손 없음. 기본 진행에 남은시간 요구 없음. 선택 점수는 안정적으로 간 거리이며 초반 실수 누적으로 완주 불가하게 하지 않는다.
- 협력 확인: 자동 안정화 상태에서 플레이어가 평지에서 출발·경사에서 멈춤을 한 번 직접 조작하고 그 이유를 관찰한다. 도우미와 함께 운반을 마친다.
- 보조: 자동 안정화, 기울기 변화 작게, 눌러유지 대신 한 번 탭 지속/해제, 정지 단계별 판단, 무시간. 빠른 연타 요구 없음.
- 역사 경계: 현대적으로 단순화한 운반 모형이다. 수레 균형을 맞췄으니 붕당대립·부패가 해결됐다는 결론 금지. 거중기 구조는 별도 검토 없이 이 수레의 기능으로 섞지 않는다.
- 보상/변화: 공사장에 운반된 돌이 놓이고 일꾼의 생활·정조의 사업 대화로 복귀. 자산: 수레기울기3~5상태,돌,경사구간3개,안전평지,일꾼멈춤동작. eng_balance_cart는 하중변수만 바꾸는 추후 운반게임에 재사용 가능.

## 8. CH06 — 곡식을 살펴보고, 되를 익혀요

- 연결 이야기: 농민이 실제 피해 표본을 보여 준 뒤, 그 옆의 별도 학습 작업대에서 곡식 관찰과 단위를 익힌다. INT-001~003의 원본 위치·소유권·약정11/요구15/추가4·최종 증거판정은 유지한다.
- 실제 조작 A/30초: 별도 연습 표본6개(ch06_practice_samples)를 확대해 '겉모습에서 손상 보임 / 더 확인 필요' 두 관찰칸에 놓는다. 모양·구멍 등 관찰 근거를 선택한다. 피해표본 ch06_grain_sample과 연습곡식 ch06_practice_grain은 서로 다른 ID·그릇·이름이다. 실제 피해 표본은 원래 꾸러미에 남고 자산을 지우거나 깨끗하게 바꾸지 않는다. '먹어도 안전함'을 외형만으로 판정하지 않는다.

## 9. CH07 — 장터의 작은 합주

- 연결 이야기: 판소리·탈놀이·한글소설·그림을 즐기는 장터에서 공연 준비를 돕는다. 판소리 감상과 관객의 참여 대화를 살리고, 별도의 두 동작 리듬놀이로 이어진다.
- 실제 조작: 두 큰 입력면 '북 한 번 / 손뼉 한 번'을 박자에 맞춰 누른다. 키보드는 F/J 또는 좌/우 방향키. 동시누름·길게누름은 최초 버전에서 제외. 같은 음을 양손으로 연타하지 않아도 되는 간격을 둔다.
- 규칙/목표:60초,72BPM 창작4박 루프(제작초기값), 쉬운패턴→쉼포함→변형3구간. 히트 초기판정±180ms, 느긋한모드±350ms. 구체 수치와 악보는 음향 담당의 제작·지연보정 검증 뒤 확정한다. 예시8박: '북 / 쉼 / 손뼉 / 쉼 / 북 / 손뼉 / 쉼 / 손뼉'. 실제 전통 장단명이나 정확 재현이라고 부르지 않는다. 음악판정은 AudioContext 기준, 무음은performance 기준의 시계로 구현하며 장치offset을 보정한다. 재개 시 마지막 안전마디로 되돌리고 4박 준비(점수·시간 제외) 후 시작한다. 부분마디 임시점수는취소하고 확정마디점수는중복반영하지않는다.
- 성공/재시도: 반주 종료는 도전 종료이며 무입력만으로 이야기 완료를 인정하지 않는다. 일반 또는 차근차근 모드에서 북·손뼉·쉼의 필수 참여를 확인한 뒤 합주 장면으로 복귀한다. 놓친 박은 관객과 동료가 이어가고 음악은 끊기지 않는다. 점수는 맞춘 수와 개인 연속기록이며 필수 점수는 없다. 실패음·야유·강제 처음부터 없이 원하는 구간을 연습할 수 있다.
- 협력 확인: 비시간8박판에서 소리와 쉬는칸을 관찰하고 플레이어가 한 칸을 직접 눌러 참여한다. 도우미가 나머지를 이어 공연을 마친다. 문화 종류와 표현의 뜻을 알리는 회고는 동일하게 제공한다.
- 보조: 시각박자/진동가능시선택/무음가능, 오디오입력지연보정, 속도75%, 한입력모드, 자동반주, 정적인박자칸. 보정에 실패하면 점수정확도를 낮추고 연습/협력권장, 기기지연을 학생실력실패로 기록하지 않는다.
- 보상/변화: 장터 관객이 함께 손뼉치고 그림에 공연마당이 복원된다. 자산: 공연자 작은동작,관객손뼉,두입력면,독자북/손뼉음원,창작반주. eng_rhythm2. 판소리의 추임새와 북을 설명할 때 두입력놀이가 판소리전통전체를 재현한다고 말하지 않는다.

## 10. CH08 — 천리경 너머, 우리 나루터

- 연결 이야기: 사신이 가져온 천리경의 쓰임을 살펴본다. 나루터의 먼 물건을 관찰한 뒤 세계지도·자명종·천주실의 이야기로 돌아간다.
- 실제 조작: 천리경의 시야를 큰방향버튼/다음구역버튼/화면드래그/방향키로 움직이고 확대단계2개를 선택한다. 목표 그림카드의 형태를 먼 풍경에서 찾아 중심에 두고 '관찰' 또는 Enter. 핀치·정밀조준 필수 없음. 확대창 안의 실제 표적은44px 이상,인접영역겹침없음을목표로 하고 설명읽기·목표확인에는시간을멈춘다.
- 규칙/목표:90초에 같은지역의 물건4개(돛대에묶인천,나루터표지,산기슭정자,먼집지붕 등)를 찾는다. 정조준 허용영역을 넓게 두고 가까워지면 중심을 부드럽게 맞춘다. 발견후 해당물건의모양·쓰임을 짧게 듣는다.
- 성공/재시도: 틀린물건을 관찰해도 시야유지, 무엇이다른지 모양힌트 제공. 시간끝 현재발견유지,나머지는 무시간/협력으로 완료. 목표가범위밖에숨거나로딩되지않아못찾는상태 금지.

## 11-1. 교차검토에 따른 규칙 보완

- CH02 첫 조립 연습은 한 음절 '나'다. 이후 '나무·바다·나라'의 두 음절 요청으로 확장한다. 정해진 초성·중성 칸의 조합과 읽기·요청 처리가 주된 기술이다.
- CH03은 정해진 정답 칸에 같은 모양을 놓기만 하는 방식에서 벗어나, 회전·겹침·빈틈을 고려해 여러 유효 배치를 찾는 공간 퍼즐로 구성한다. 재료를 모두 놓아도 빈틈이 있으면 배치를 되돌려 고친다. 실제 판 데이터는 적어도 두 유효 해가 있는지 제작 시 검사한다. CH01의 길 연결, CH02의 음절 규칙과 구분한다.
- CH04 주민은 충돌 대상이나 점수 대상이 아니다. 코스 생성기는 각 구간의 현재 레인에서 다음 안전 레인까지 이동 가능한지 검사한다. 필요한 레인 이동 수×전환 시간+입력 여유보다 예고 시간이 긴 배치만 채택하고, 최소 하나의 안전 경로를 유지한다. 저프레임·프레임 지연 때 장애물을 순간 이동시켜 충돌시키지 않고 시뮬레이션을 멈춘다. 재개는 정지 출발과 초기값 2초의 무장애 유예를 제공한다.
- CH07 일반 모드 반주는 72BPM 72박, 24박씩 세 구간으로 약60초다. 75% 속도는 54BPM으로 같은72박이 약80초이며, 반주·시각 신호·판정 모두 같은 템포 지도를 사용한다. 박 단위 악보를 다시 시간으로 계산하고 반주는 이 템포에 맞는 독자 음원을 별도 준비하거나 품질 검증된 동기 방식으로 제공한다. 반주와 판정 속도를 따로 바꾸지 않는다.
- CH07 곡이 끝난 것은 runFinished이지 학습 완료가 아니다. 이야기 복귀 전 일반/도움 모드 모두 '북 한 번, 손뼉 한 번, 쉼의 의미 확인'을 직접 수행하거나 단계별 참여로 확인한다. 정확한 타이밍 점수는 요구하지 않으며 무입력이면 결과에서 차근차근 완료하기를 안내한다.
- 리듬 중단 시 이미 확정한 마디 점수는 유지하고 미완료 마디 점수·콤보 초안은 안전 마디 지점으로 되돌린다. 4박 준비 동안 점수·플레이 시간은 흐르지 않으며 이미 확정한 점수를 다시 더하지 않는다. 모드 변경은 일시정지 후 안전 지점에서 적용하고 다른 규칙의 최고기록을 덮어쓰지 않는다. audio/casual-minigames.md의 시계·보정·세대 취소 규칙을 함께 따른다.
- CH06은 피해표본 ch06_grain_sample, 분류 연습표본 ch06_practice_samples, 계량 연습곡식 ch06_practice_grain의 이름·ID·그릇을 분리한다. 새로운 놀이 범위는 ch06-integration.md INT-004에 승인 기록을 남겼으며 과거 피해의 증거 판정은 유지한다.
