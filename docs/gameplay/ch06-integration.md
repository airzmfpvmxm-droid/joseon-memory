# CH06-003 곡식 창고 통합 계약

총괄 결정 v0.1 / 2026-11-18 / 운영 v1.1

아래는 제작을 위한 명세다. 실행 코드·완성 자산·브라우저 검증이 존재한다는 뜻이 아니다. 부서 문서의 충돌은 이 계약의 INT 결정으로 조율한다. 향후 변경은 결정 ID와 영향 문서를 함께 갱신한다.

## INT-001 공간과 소유
- 농민 ch06_farmer는 처음부터 보이며, 보고 뒤에도 앉은 채 몸을 조금 편다. 갑자기 일어서거나 사라지지 않는다.
- 곡식 표본 ch06_grain_sample은 농민 옆 바닥의 작은 꾸러미다. 장면 정규화 앵커 (.43,.89)는 설계값이며 실제 그림·입력 검증 전이다.
- 낮은 탁자에는 봄 대여 기록 ch06_loan_record가 놓인다.
- 가을 요구 쪽지 ch06_demand_note는 농민 소유다. 손에 펼쳐 보여 주며 별도 작은 클릭 영역을 만들지 않는다. 농민 대화와 자료 재열람으로 연다. 획득·반납 임무를 추가하지 않는다.
- 겹창을 닫으면 종이와 표본은 해당 소유자·위치에 남는다. 보고 뒤의 변화는 농민의 자세·표정·대사와 그림 복원이다.

## INT-002 판정과 학습 범위
- 게임용 가상 수치: 지급10되 + 처음 안내된 이자1되 = 약정11되, 가을 요구15되, 사적 추가요구4되.
- 이 수치를 당시 조선 전체의 표준 이율·실재 사료 인용으로 제시하지 않는다.
- 비교는 약정 기록과 요구 쪽지에 근거한다. 벌레 먹은 곡식 표본과 농민의 증언은 품질 고충이며, 최초 지급 총량이나 추가4되의 단독 증거가 아니다.
- 최종 보고는 추가 요구의 근거와 품질 고충을 모두 남긴다. 정책 전체의 개선·세금 취소·관리 처벌이 자동 완료되지는 않는다.

## INT-003 상태·입력·음향
- 첫 대화 → 기록·쪽지·표본 확인 → 비교 가능 → 계산과 근거 연결 → 주민 보고 → 세션 내 완료.
- 조사 순서는 자유다. 세 자료 확인 전에는 비교 완료를 확정하지 않는다. 요구 쪽지는 농민 또는 자료 화면에서 다시 확인할 수 있다.
- 선택 후 놓기를 기본으로 하여 마우스·탭·키보드로 모두 진행한다. 드래그는 후순위 선택 기능이다.
- 학습 완료와 영속 저장 성공 여부를 구분한다. 저장 실패 시 세션 진행은 유지하고 보존 실패와 재시도를 알린다. 저장이 차단됐다는 이유로 학습 완료를 막지 않는다.
- 기존 joseon-village 저장 데이터와 별도 네임스페이스를 사용한다. 구체 스키마는 구현시 검증한다.
- 문서 열기는 ui_document_opened {objectId} 하나로 발행한다. objectId는 ch06_loan_record 또는 ch06_demand_note. 개별 opened 이벤트를 중복 발행하지 않는다.
- ch06_*_checked는 진행 상태, 문서 열기는 실제 사용자 행위다. 상태 복원으로 과거 효과음·완료음을 재생하지 않는다.
- 곡식 붓기 소리는 실제 붓기 동작이 구현된 경우만 사용한다. 필수 계량 시뮬레이션을 추가하지 않는다.

## 제작 전 확인
- 담당별 최종 문서와 QA 기록을 읽고 일관성을 확인한다.
- 이번 검토는 설계 검토다. 실제 태블릿, 크롬북, 터치·키보드, 저장 복구, 이미지·음향 검증은 구현 뒤 수행한다.
- 다음 작업은 확정 명세에 맞는 독자 자산 제작과 실행 가능한 시범 구간 구현이다.

## INT-004 캐주얼 미니게임 보완 / 운영 v1.2
- 사용자 장르 다양화 요청에 따라 별도 연습 표본의 분류와 연습 곡식의 되 계량을 추가한다. INT-003의 '필수 계량 시뮬레이션을 추가하지 않는다'는 이전 범위 제한은 이 연습 활동에 한해 갱신한다. 역사적 증거판정에는 계량 손기술 점수를 요구하지 않는다.
- 기본 체험과 차근차근 완료하기를 함께 제공한다. 정밀한 수위·속도 점수를 다음 이야기의 필수 조건으로 사용하지 않는다.
- 원본 피해 표본은 농민 옆의 ch06_grain_sample로 보존한다. 연습 표본과 계량용 곡식은 별도 ID·그릇·이름으로 구분한다. 옛 피해 물건이 깨끗해지거나 사라지는 연출을 만들지 않는다.
- 자세한 조작·초기 난도·연습 자료는 CASUAL-MINIGAMES.md, 공통 이벤트는 MINIGAME-SYSTEM.md의 CM-INT-001을 따른다.
- 기존 기록·쪽지 비교, 가상 수치, 증거의 범위, 농민 보고와 저장 원칙은 그대로 유지한다. 현재는 명세 갱신이며 새 미니게임이 구현됐다는 뜻이 아니다.
