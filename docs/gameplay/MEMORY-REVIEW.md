## 확인 범위

실제 Chrome·Playwright로 8장 도움 모드·주민 대화·귀환·그림 복원·생각 남기기·결말을 통과했다. 각 질문에서 부적절한 선택과 설명을 먼저 확인한 뒤 적절한 선택을 눌렀으며, 완료 상태나 게임 시계를 주입하지 않았다. 새로고침 후 8개 생각 기록이 유지됨을 확인했다.

1024×768에서 8개 되짚기 창과 복원 화면을 검사하고, 기존 768×1024·1366×768 그림첩 경로를 재검사했다. 실제 기기·학생 이해도·모든 질문의 모든 크기 조합은 미검증이다.

배포 소스 `80db1e6a80fc99f1702a4161d467c92515ef968b`, 배포 상태 `succeeded`. 실제 배포 URL에서도 같은 통합 검사를 실행해 되짚기 8개·질문·재방문·결말·저장·해당 화면 크기의 경로를 통과했다. 페이지 예외·실패 HTTP 응답은 기록되지 않았다.
