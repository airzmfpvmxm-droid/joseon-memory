# 기억 그림첩과 주민 추가 대화 — 2026-11-20

## 구현

- 홈과 탐험 화면에서 ‘만난 사람과 기억’을 연다. 네 장씩 두 페이지로 나누어 시대·현재 목표·완료한 기억·만난 주민·배경 조사·추가 대화 수를 표시한다.
- 완료한 장소는 재방문할 수 있다. 아직 열리지 않은 장은 잠근다. 현재 장은 ‘현재 이야기로’로 돌아간다.
- 주민마다 두 가지 선택 질문을 제공한다. 선택에 따른 답변을 듣고 다른 질문으로 돌아가거나 대화를 닫는다. 정답 선택·호감도 점수·보상과는 연결하지 않는다.
- `story.asked`에 나눈 질문의 키(`1:0`~`8:1`)를 저장한다. 기존 저장은 빈 질문 목록으로 안전하게 이관한다.
- 재방문은 별도 임시 위치로 실행한다. 현재 이야기의 phase·대사 위치·복원 수·위치는 변경하지 않으며, 재방문에서 같은 기억을 다시 획득할 수 없다.
- 재방문 주민의 대화창을 닫은 뒤에도 이동 프레임이 계속 실행되도록 탐험의 대화 진입 처리를 보완했다.

질문은 기존 장별 학습 주제와 창작 놀이의 구분을 설명한다. 이번 작업에서 교과서 전체를 새로 대조한 것은 아니다. 선택에 따라 사건 결말이나 주민 성격이 달라지는 서사 분기까지 구현하지 않았다.

## 검증

Chrome·Playwright 실제 버튼 입력으로 각 장의 질문 두 개, 총 16개 답변을 열고 원래 이야기로 복귀했다. 첫 장을 완료하고 둘째 장 진행 중 첫 장으로 돌아가 주민과 대화한 뒤 다시 움직이고 복귀했다. 전후의 현재 장 phase·대사 위치·복원 수·위치가 동일함을 저장 데이터 읽기로 비교했다. 완료 상태를 주입하지 않았다.

도입 → 8개 도움 모드 놀이 → 귀환 → 결말과 기존 선택 메뉴를 이어서 확인했다. 그림첩의 완료한 8장 상세를 1024×768, 768×1024, 1366×768에서 확인했다. 첫 장의 질문·대화·탐험은 기존 동일 크기의 경로로 확인한다. 실제 기기·학생 이해도·모든 장의 모든 화면 조합은 미검증이다.
