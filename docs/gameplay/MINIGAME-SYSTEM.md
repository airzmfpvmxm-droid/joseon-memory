# 캐주얼 미니게임 공통 구현 계약

총괄 명세 v0.2 / 운영 v1.2 / 2026-11-19

사용자 요청에 따라 퍼즐·리듬·레이싱 등 직접 조작의 재미를 챕터에 추가한다. 이 문서는 구현 준비 명세이며 실행 코드·시연 가능한 게임은 아직 없다. 장별 규칙과 조정값은 CASUAL-MINIGAMES.md, 독립 검토는 ../qa/casual-minigames-review.md를 참조한다.

## 역할 분리
- 탐험·주민 대화는 미니게임의 시작 이유와 결과를 제공한다.
- 미니게임은 직접 조작, 즉시 반응, 익힐 수 있는 기술, 재도전 목표를 갖는다. 정답 선택에 효과만 붙인 형태로 대체하지 않는다.
- 역사적 판단은 대사·근거에 연결한다. 손놀림 점수를 역사 이해 점수로 취급하지 않는다.
- 점수·연속 성공·개인 최고기록은 추가 도전이다. 특정 점수나 반응 속도를 다음 이야기의 필수 조건으로 만들지 않는다.
- 일반 모드 실패는 짧게 재도전한다. 도움 모드는 속도·표적 크기·입력 부담을 조절하며, 필요한 활동을 도움받아 수행하면 이야기를 이어간다. 도움 사용에 감점·낙인·보상 차등을 두지 않는다.

## 공통 상태
준비 → 조작 연습 → 플레이 → 결과 → 장면 복귀. 일시정지는 별도 상태다.
- 준비에서 목표와 조작을 짧게 보여 주고 직접 한 번 해 본다.
- 이야기 임무 중 나가면 임무를 실패로 확정하지 않는다. 다시 시작할지, 지원되는 안전 지점에서 재개할지 안내한다.
- 화면 회전·탭 숨김·설정/자료창 열기는 시간 판정과 입력을 멈춘다.
- 리듬은 준비 카운트 뒤 안전한 마디에서, 레이싱은 정지 상태에서 다시 출발한다. 멈춰 있던 동안의 입력·장애물·미스를 한꺼번에 적용하지 않는다.
- 결과에서 다시 하기와 이야기 계속을 구분한다. 이미 끝낸 미니게임의 반복 결과가 이야기 완료를 취소하지 않는다.

## 공통 데이터 제안
게임 ID, 챕터 ID, 엔진 ID, 목표, 모드, 연습 여부, 설정 버전, 판정 설정, 자산 목록, 입력 매핑, 도움 단계, 이야기 결과, 개인 최고기록, 안전 재개 정보.
- 결과 예: completed / assistedCompleted / retry / exited. 앞의 두 결과는 이야기 진행에서 동등하다.
- 기록은 입력 지연·모드가 다른 결과를 단순 비교하지 않는다. 속도 완화 모드의 기록은 별도로 보관하되 학생 간 우열로 표시하지 않는다.
- CM-INT-001 이벤트: minigame_started, minigame_paused, minigame_resumed, minigame_finished. payload는 chapterId·minigameId·runId·mode·result를 사용한다. 종료 별칭 minigame_completed는 발행하지 않는다.
- minigame_story_confirmed는 장별 필수 관찰·선택·조작을 확인한 뒤 별도 한 번만 발행한다. 무입력으로 시간이 끝난 것만으로 이야기 완료를 확정하지 않는다. 결과에서 보조 경로로 이어 필수 활동을 함께 완료할 수 있으며 높은 점수는 요구하지 않는다.
- runId는 한 시도에서 고정한다. 중단·재개 때는 오디오/구간 세대만 갱신하고, 새 시도를 시작할 때만 runId를 바꾼다.
- 임무 보상은 최초 완료에 한 번만 반영한다. 다시 하기는 연습과 최고기록 갱신이며 보상 반복 수령으로 이어지지 않는다.
- 진행 상태와 영속 저장 성공 여부를 분리한다. 저장 실패 중에도 세션 내 플레이·완료를 유지한다.

## 입력과 화면
- 태블릿 한 화면, 페이지 전체 스크롤 없음. 좁은 화면은 조작 영역을 재배치하며 장면 전체를 축소해 버튼까지 작게 만들지 않는다.
- 터치와 키보드 모두로 진행한다. 마우스 hover·정밀 드래그·멀티터치·기기 기울이기를 필수로 요구하지 않는다.
- 조립/배치: 선택→목적지 선택. 드래그는 선택 기능.
- 레이싱: 좌/우 화면 버튼 또는 키보드. 스와이프는 보조 기능. 캐릭터가 화면 밖으로 빠지는 자유 조향은 초기 범위에서 제외한다.
- 균형: 화면 좌/우 버튼으로 조정. 실제 기기 기울이기를 요구하지 않는다.
- 리듬: 큰 두 입력 영역. 음악·시각 신호를 함께 제공하고, 음소거로도 플레이할 수 있는 별도 시각 모드를 둔다.
- 색·소리 한 가지로만 구분하지 않는다. 정답에 필요한 표시는 형태·위치·글을 함께 사용한다.

## 재사용 엔진
| 엔진 | 주요 기능 | 적용 |
|---|---|---|
| eng_tileboard | 선택·회전·배치·연결·정합 검사 | 1장 길, 2장 자모, 3장 수리 |
| eng_runner3 | 3개 차선·장애물·속도·구간 재시도 | 4장 보급 운반 |
| eng_balance_cart | 무게·무게중심·흔들림·좌우 조정 | 5장 돌 운반 |
| eng_sort_measure | 표본 분류·되 단위 조절·수량 피드백 | 6장 곡식 관찰과 조작 |
| eng_rhythm2 | 오디오/시각 기준 시계·입력 판정·지연 조절 | 7장 합주 |
| eng_observe | 시야 이동·확대·관찰 대상 찾기 | 8장 천리경 |

엔진은 재사용하되 목적과 핵심 조작은 장별로 다르게 한다. 정확한 물리 모델·BPM·판정 시간·조정 속도·초기 난도는 프로토타입과 학생 관찰 후 조정한다.

## 6장 기존 설계와의 관계
기존 증언·기록 비교와 추가 요구 판정은 유지한다. 곡식 관찰에 분류 조작을, 수량 모형 비교에 되 단위 조작을 보완한다. 미니게임 결과로 벌레 먹은 곡식이 좋은 곡식으로 바뀌거나 과거 지급 총량이 입증되는 연출은 하지 않는다. 손기술만으로 부정 판정이 완료되지 않는다.

## 구현 순서와 검증
1. 공통 화면·입력·일시정지·저장 결과 처리.
2. 기존 시범 범위인 6장에 분류·계량과 조사·비교를 연결하여 최초 플레이 데모 제작.
3. 7장 리듬, 4장 레이싱을 구현해 장르별 입력·시간 판정의 재사용 가능성 검증.
4. 배치 엔진의 1·2·3장, 균형의 5장, 관찰의 8장 확장.

이 순서는 작업 우선순위이며 일정 약속이나 완료 보고가 아니다. 실제 난도·재미·터치·화면 맞춤·음향 지연은 플레이 테스트로 확인한다.
