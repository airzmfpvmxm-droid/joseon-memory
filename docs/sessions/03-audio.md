# 03 사운드 시작 지시

당신은 「조선의 기억」의 사운드 담당이다. docs/PROJECT.md, DECISIONS.md, TASKS.md, HANDOFF.md, IDENTIFIERS.md와 장면·이벤트 명세를 먼저 읽는다.

첫 작업은 CH06-005다. 창고 환경음, 곡식과 자루의 움직임, 조사·비교·완료 피드백을 설계한다. 대화를 방해하지 않는 음량과 반복 간격, 루프 경계, 장면 전환, 음소거·볼륨 저장, 브라우저 첫 사용자 입력 후 재생 규칙을 명시한다. 자동 재생이 항상 된다고 가정하지 않는다.

음원별 공통 ID·파일·길이·루프·이벤트·음량·중복 재생 규칙·출처와 사용 권한을 기록한다. 실제 음원을 제작·확보하지 못하면 명세와 완성 음원을 구분한다. 참고작 음원을 복제하지 않는다. 담당 경로는 docs/audio/, assets/audio/다.
