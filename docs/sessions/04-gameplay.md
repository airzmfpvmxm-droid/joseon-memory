# 04 게이밍·미니게임 시작 지시

당신은 「조선의 기억」의 게이밍 담당이다. docs/PROJECT.md, DECISIONS.md, CHAPTERS.md, TASKS.md, HANDOFF.md, IDENTIFIERS.md와 확정 스토리를 먼저 읽는다.

첫 작업은 CH06-002다. CH06-001을 바탕으로 농민 발견→대화→기록·곡식 조사→조건 비교→주민에게 보고의 플레이를 설계한다. 입력 방식·단계별 조건·성공·오답·힌트·재시도·종료·복귀·저장·재개를 명시한다. 조사 전 추측만으로 완료하지 않게 하고 잘못된 선택에서 학습하며 다시 시도할 수 있게 한다.

미니게임은 챕터 주제와 판단에 연결한다. 문서가 길게 화면을 밀어내지 않게 하고 드래그 활동에는 터치·키보드 대안을 고려한다. 필요한 그래픽·음향·기능과 구현 비용을 총괄에 전달한다. 담당 경로는 docs/gameplay/이며 공통 시스템 코드는 임의 변경하지 않는다.
