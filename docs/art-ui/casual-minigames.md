# 8개 챕터 캐주얼 미니게임 — 그래픽·UI 명세

담당: 02 그래픽·UI / 버전 v0.2 / 2026-11-18

소유 파일: docs/art-ui/casual-minigames.md. 기준 입력: 04 게이밍 담당이 공유한 8장 초안과 프로젝트 공통 원칙. 관련 게임 명세: docs/gameplay/CASUAL-MINIGAMES.md. 이 문서는 기획 보완이며 이미지 생성·코드 구현·실제 화면 검증을 수행하지 않았다. 참고 영상은 직접 재생 내용을 확인하지 못했다.

## 공통 화면 구조

캐주얼 활동 중에도 따뜻한 한지·목재·흙·볏짚의 색과 갈색 외곽선, 붓 질감을 유지한다. 정답을 고르는 추상 카드만 나열하지 않고, 손으로 조립·옮김·관찰하는 실제 물건의 모양을 사용한다. 퍼즐 조각 선택 표시·조작 버튼·남은 시간은 게임 UI로 명확히 분리하며 배경 속에 임시 사각 아이콘을 띄우지 않는다.

기본 3행은 `상단 안내 / 가운데 활동 / 하단 조작`이다. 각 행을 별도 레이아웃 영역으로 유지하여 점수나 대화가 활동판 위로 겹치지 않게 한다. 전체 앱은 안전 영역을 제외한 100dvh 안에서 배치하며 body 스크롤을 만들지 않는다. 실제 가용 뷰포트는 QA가 기록한다.

| 뷰포트 | 상단·하단 제안 | 가운데 활동 영역 | 확인할 설계 위험 |
|---|---|---|---|
| 1024×768 | 상단48px, 하단176px, 행간·안전 여백32px | 남은512px, 내부 최대960×480의 활동판 | 게임판과 손조작 버튼이 분리되고 대사가 판을 덮지 않아야 함 |
| 768×1024 | 상단48px, 하단200px, 행간·안전 여백32px | 남은744px, 내부 최대704×704의 활동판 | 세로 화면에서 조각 팔레트를 아래/페이지로 전환, 글씨 축소 금지 |

수치는 설계값으로 테스트 통과 수치가 아니다. 브라우저 상단 UI와 글자 확대가 가용 높이를 줄이면 설명을 쪽 전환하고 활동판 내부를 재배치한다. 역사 지도처럼 고정된 배치를 임의 변형하지 말아야 하는 판은 비율을 유지하고 남는 공간에 목표 안내를 둔다.

- 본문18~20 CSS px, 최소 터치44×44 CSS px. 좌우 이동·기울기 조절 등 반복 조작은64×64px 이상을 목표로 한다.
- 하단바에는 주요 조작과 `도움 / 잠깐 쉬기 / 차근차근 완료하기`를 두며 큰 버튼이 부족하면 보조 메뉴로 묶는다. 조작 버튼이 NPC·미션 소품으로 보이지 않게 한다. `이야기 계속`은 필수 활동을 마친 결과 화면에서만 제공한다.
- 진행 중 긴 자료는 모달 한 장으로 열고 타이머·자동 이동을 정지한다. 초기 초점, 내부 Tab 순환, 배경 inert, 닫은 뒤 초점 복귀를 지킨다.
- 결과는 판을 밀어내지 않는 겹창으로 표시한다. 다음 진행을 학생이 누르기 전 자동 종료하지 않는다. 컷신 영상을 넣지 않는다.

## 한 화면 조작 상세

### 퍼즐·조립·분류

- CH01은 고정된 길칸의 회전 퍼즐이다. 아래 선택→배치 규칙은 CH02·03 조립과 CH06 분류에 적용하며 CH01에 조각 팔레트를 추가하지 않는다. 회전은 타일탭/Enter와 별도회전버튼으로 같은 동작을 수행한다.
- 선택된 조각을 유지한 채 다음 칸을 누르면 놓인다. 놓기 전에 손가락을 계속 누르고 있을 필요가 없다.
- 집을 수 있는 조각, 놓을 수 있는 칸, 현재 선택은 모양·선택표시·접근성 이름으로 함께 구분한다.
- 조각이44px보다 작아지면 조각 수를 한 페이지에 줄인다. 팔레트 페이지 전환은 활동 전체를 스크롤하지 않는다.
- 잘못 놓은 물건은 파괴되지 않는다. 원위치로 돌아가고 다음 시도가 가능하다. 실패 모션 중에도 다음 선택 상태를 보존한다.

### 운반·균형·리듬

- 가운데 활동판에 조작버튼을 겹치지 않는다. 손가락이 캐릭터·장애물을 가리지 않게 하단바에 둔다.
- 3레인은 물리적 화면좌표 대신 레인번호를 기준으로 판정한다. 창 크기 변경 중 타이머·이동은 일시정지한다.
- CH04 수레의 기본 충돌은 동행이 안전하게 정리하는 작은 멈춤으로 보여 준다. 떨어진 보급품은 사라지거나 파괴되지 않고 낮은 점수가 피란민 생존 실패로 연결되지 않는다.
- 수레의 기울기와 조작표시는 하단바에도 숫자/말로 제공한다. 각도나 색만으로 상태를 알게 하지 않는다.
- 리듬은 소리 이외에 타점과 짧은 예고를 제공한다. 시각·청각·운동 제한에 따라 감상/한박씩 선택으로 같은 학습 장면을 진행할 수 있다.

### 탐색

- 목표의 가시적 그림이 작으면 확대 관찰창으로 바꾸고44px 이상의 서로 떨어진 입력영역을 제공한다.
- 화면 밖으로 천리경을 끌거나 아주 느린 시선 추적을 요구하지 않는다. 구역 버튼과 표적 순환 키로 모든 대상을 방문할 수 있다.
- 단순 위치 암기 대신 발견한 물건의 용도·사람의 생활과 연결되는 짧은 관찰을 보여 준다. 읽는 동안 시간은 흐르지 않는다.

## 보조 입력과 결과

도움 모드는 시작 전과 활동 중 언제든 선택할 수 있다. `무시간 / 한 동작씩 / 단계 힌트`를 설명하고 사용 사실을 실패 표시나 감점 사유로 노출하지 않는다. `차근차근 완료하기`를 고르면 무시간·한 동작씩 진행으로 전환하고 필수 관찰·읽기·선택을 직접 마친 뒤 같은 이야기 진행과 보상을 제공한다. 보조모드의 기록은 시간도전 점수와 분리하되 진행 보상은 동등하게 한다. 손 움직임이 느린 학생에게 짧은 타이밍·연속누름·동시누름을 요구하지 않는다. 선택→배치 대안만으로 조립·분류를 마칠 수 있어야 한다.

기본 제한시간은 04 초안의 제안값이다. 설명·조작연습·자료읽기·일시정지·겹창·포커스상실에서는 정지한다. 시간종료는 생명손실이나 진행불가가 아닌 `다시하기 / 차근차근 완료하기` 선택으로 이어진다. 후자는 필수 활동을 자동 완료하지 않는다. 필수 활동을 모두 마쳤을 때만 결과 화면의 `이야기 계속`을 활성화한다. 실력 점수와 이야기 진행 잠금을 분리하고 전체 역사 사건을 실패로 처리하지 않는다.

게이밍 v0.3에서 길 회전 조작, 선택→배치 대안, 64px 조작 영역, 자료·설명 중 타이머 정지, 확대 표적, 차근차근 완료하기와 결과 화면의 이야기 계속 구분을 대조했다. 02-CM-01~04의 요청은 문서상 반영되어 있다. 실제 UI·화면 크기·터치 검증은 없으며, 이 기록은 총괄 확인이지 기존 아트 담당의 후속 재검토 기록은 아니다.
