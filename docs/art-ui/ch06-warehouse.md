# CH06 곡식 창고 — 그래픽·UI 사전 명세

작업: CH06-004 사전 설계 / 담당: 02 그래픽·UI / 버전: v0.3 / 2026-11-18

기준: PROJECT.md 운영 v1.0, IDENTIFIERS.md, CHAPTERS.md. 이 문서는 구현 인터페이스 확정 전의 제작 제안이다. 이미지 생성·UI 구현·브라우저 플레이 검증은 아직 하지 않았다. 참고 영상의 재생 화면·음악을 직접 확인하지 못했으므로 영상 관찰 결과로 표현하지 않는다.

## 장면 목표

창고에 들어오면 학생이 바닥의 장부보다 어려움을 겪는 농민을 먼저 발견한다. 농민이 빈 자루를 잡고 창고 입구 옆에 앉아 있다. 대화를 시작하면 기록이 놓인 낮은 나무 탁자와 자기 옆 바닥의 작은 곡식 꾸러미를 손으로 가리킨다. 되는 탁자 쪽에 놓인 일반 관찰 물건이다. 조사 대상은 원래 그 장소에 있어야 하는 물건으로 그린다.

꿀빛 볏짚·낡은 목재·흙벽과 갈색 외곽선, 붓 질감, 문에서 들어오는 한 방향의 빛을 독자적인 아트 기준으로 제안한다. 실제 배경 확정 후 색상·외곽선 굵기·원근을 고정한다. 참고작이나 기존 게임의 이미지 자산을 복제·전용하지 않는다.

그림·입력 영역·반짝임은 하나의 transform을 공유한다. 고정 화면 좌표나 서로 다른 비율 계산을 쓰지 않는다. 클릭 영역 좌표는 대상 로컬 기준 polygon으로 관리하고, 겹침 검사에서 이웃 대상과 분리한다. 전경 물건 z-order와 입력 우선순위를 일치시킨다.

최소 터치 영역 목표는 44×44 CSS px, 가능하면 48×48이다. 영역 확장으로 옆 물건과 겹치면 대상을 더 떨어뜨리거나 해당 작업 면을 확대한다. 한 픽셀의 종이 모서리를 정확히 누르게 하지 않는다. 배경 자체에 그려진 조사 대상은 투명 영역만 연결하고 같은 그림을 다시 얹지 않는다.

## 태블릿 한 화면 구성

앱 루트는 현재 사용 가능한 뷰포트 높이(100dvh)를 사용한다. 높이 고정 수치의 단순 합으로 페이지를 늘리지 않으며 body 페이지 스크롤을 만들지 않는다. 기기 안전 영역과 브라우저 바가 차지하는 공간을 반영한다. 높이가 부족하면 장면이 먼저 줄고, 글자는 읽기 가능한 크기를 유지한다.

기본 구조는 상단 최소 HUD / 중앙 장면 / 하단 대화 영역의 세 행이다. 장면은 비율을 유지해 contain하며 상호작용 물건을 잘라내지 않는다. 대화창은 장면 밖의 고정 행에 두어 농민의 얼굴이나 조사 물건을 덮지 않는다.

| 화면 크기 | 제안 배치 | 확인할 위험 |
|---|---|---|
| 1024×768 가로 태블릿 | HUD 44px, 여백·안전 공간 24px, 대화 160px, 남은 540px에 장면 contain. 조사 창은 뷰포트 안 94% 이하 | 농민과 문서가 모두 보임, 버튼과 글씨 잘림 없음 |
| 1180×820 가로 태블릿 | HUD 48px, 여백 24px, 대화 168px, 남은 580px에 장면 contain | 넓어진 화면에서 오브젝트와 클릭 위치가 어긋나지 않음 |
| 768×1024 세로 태블릿 | HUD 48px, 대화 최대 208px, 장면 contain. 가로 분할 패널은 사용하지 않고 조사·비교 창을 한 장씩 전환 | 작은 물건의 최소 터치 크기, 긴 대사 페이지 수. 특정 방향 회전을 강제하지 않음 |
| 1366×768 크롬북 | HUD 44px, 대화 160px, 장면 contain. 좌우 여백 허용. 동일 화면에서 마우스·키보드 입력 | 큰 화면 너비 때문에 장면 아래가 잘리지 않음, 포커스 순서 |

표의 수치는 설계 예시다. 실제 브라우저 주소창 포함 여부, 확대율, 시스템 글꼴 배율에 따라 가용 크기가 달라지므로 QA는 측정한 inner viewport를 기록한다. 실제 기기 검증 전 통과로 표기하지 않는다.

본문 글씨는 기본 18~20 CSS px를 제안한다. 스토리와 협의해 대사는 한 상자 1~2문장, 약 45자 내외를 기준으로 2~3줄에 나눈다. 긴 설명은 페이지를 나눈다. 버튼 높이는 44px 이상을 목표로 한다. 전체 글씨를 작게 만들어 맞추지 않는다. 설정에서 글자 확대 시 대사 페이지 수를 늘린다.

## 조사·비교 창

- 자료 창은 장면 위 한 장만 열린다. 배경 입력을 막고 닫기·뒤로가기를 명확히 구분한다. 닫으면 원래 물건으로 포커스를 되돌린다.
- 겹창은 dialog 의미와 접근성 제목을 제공한다. 열릴 때 제목에 초점을 주어 내용을 안내한 뒤 첫 조작으로 이동할 수 있게 한다. Tab/Shift+Tab 초점은 겹창 내부에서 순환하며 배경은 inert 처리한다. Escape는 자료 창만 닫고 게임 진행을 초기화하지 않는다. 닫은 뒤 원래 대상이 사라졌다면 현재 목표의 조작 또는 장면 제목으로 초점을 복귀시킨다.
- 한지 바탕 위 실제 글자로 제목·수치를 표시한다. 제목 제안: `곡식 대여 기록`. 주민 진술과 기록의 날짜·양을 혼동하지 않도록 출처명을 계속 보인다.
- 비교 화면은 두 자료의 핵심 요약을 항상 함께 보인다. 가로 화면은 좌우, 세로 화면은 짧은 요약 두 개를 위아래로 배치한다. 긴 원문만 쪽 전환으로 열고 비교 화면으로 돌아오면 선택과 근거를 유지한다.
- 스토리·게이밍 협의 수치: 봄 지급 10되 + 약정 이자 1되 = 상환 11되, 요구 쪽지 총 15되 중 `아전의 몫 4되`를 연결한다. 금액 차이만 강조하는 붉은 오답 표시 대신 요구 쪽지의 부당 추가 행을 학생이 고르게 한다. 장면 문서의 글자 배열·상세 내용은 스토리 원문을 따른다.
- 클릭·터치로 근거를 선택한 뒤 지정 위치를 누르는 대안을 제공한다. 끌어 놓기만으로 완료하게 하지 않는다. 키보드는 Tab 이동, Enter/Space 선택, Escape 닫기를 지원한다.
- 게임용 가상 수치 안내는 제작·학습 자료의 적절한 설명 위치에 둔다. 장면 속 문서 그림마다 현대적인 `게임용 문서` 문구를 삽입하지 않는다.

## 상태와 작은 동작

| 진행 상태 | 농민 | 소품·반짝임 | 지속되는 결과 |
|---|---|---|---|
| 미대화 | 걱정하며 빈 자루를 쥠 | 농민 가장자리만 간헐적 별 | NPC와 물건은 실제로 보임 |
| 대화 후 조사 가능 | 필요한 위치를 한 번 가리킴 | 미확인 조사 대상만 개별 별 | 방문·대화 상태 저장 |
| 근거 조사 완료 | 재대화 시 다음 위치 안내 | 조사한 대상의 별 제거, 실물은 남음 | 장부 펼침/확인 모습 저장 |
| 비교 완료, 보고 전 | 플레이어 쪽을 바라봄 | 농민 가장자리만 별 | 다시 비교 가능, 근거 보존 |
| 보고 완료 | 안도하지만 문제가 모두 끝난 것처럼 과장하지 않음 | 임무 별 제거, 관찰 가능 | 표정·완료 대사·저장 상태 유지 |

장부는 주운 문서와 달리 창고의 비치 기록일 수 있으므로 조사만으로 사라지지 않는다. 최종 소품 사용·회수 방식은 스토리/게이밍 명세에 따른다. 실제 곡식을 옮기는 규칙이 확정되지 않으면 옮겨진 자루 상태를 임의 추가하지 않는다.

교차검토 및 총괄 조율로 확정한 시각 구분: 요구 쪽지는 농민이 대화 중 손에서 펼쳐 보여 주고 소유를 유지한다. 쪽지는 별도 픽셀 클릭을 요구하지 않으며 농민 클릭 영역 안에 추가 입력 영역을 중첩하지 않는다. 내용은 자료에서 재열람할 수 있지만 획득·인벤토리 물품 이동으로 표현하지 않는다. 장부는 낮은 탁자에 남는다. 벌레 먹은 곡식 표본은 농민 옆 바닥 작은 꾸러미에 두며 관찰 후 제자리에 놓이고 복제되지 않는다. 표본은 봄에 받은 곡식의 남은 일부라는 주민 증언과 함께 보이며, 외형만으로 과거 지급 상태를 확정하지 않는다. 되는 일반 관찰용이므로 필수 임무 별을 표시하지 않는다. 농민은 보고 후 앉은 상태에서 움츠린 몸을 조금 펴고 고개를 든다. 일어서기·자루 이동은 이 구간에 추가하지 않는다.

반짝임은 대상 가장자리나 바로 옆의 6~12 CSS px 금빛 별 하나, 짧은 출현과 충분한 휴지기로 표현한다. 네모 테두리·큰 번짐·계속 점멸을 사용하지 않는다. 일반 관찰 대상은 hover·focus 때 윤곽 또는 작은 이름표로 구분한다. 접근성 포커스는 명확한 외곽 표시를 허용하되 평상시 임무 네모 프레임으로 남기지 않는다. reduced-motion에서는 반복 동작·별 점멸을 멈추고 작은 정적 표식이나 목표 안내를 제공한다.

## 이미지 결손·접근성

- 배포 전 자산 목록·모든 상태 파일·로딩을 검사한다. 실패는 QA 오류다.
- 로딩 중/실패한 대상을 투명한 클릭 영역만 남긴 채 진행시키지 않는다. 이모지·사각 아이콘을 배경에 대체 표시하지 않는다.
- 실제 실행 중 결손 발생 시 화면 상단에 짧은 재시도 안내를 띄운다. 농민 또는 현재 조사 대상을 열 수 없으면 `현재 조사 다시 열기` 복구 UI로 같은 텍스트 근거에 접근하게 한다. 확인하지 않은 근거를 자동 수집 처리하지 않는다.
- 전체 이미지의 장면 설명, 대상 접근성 이름, 현재 조사/완료 상태를 텍스트로 제공한다. 물건의 구분을 색이나 반짝임에만 의존하지 않는다.

## 타 부서 검토 요청 및 기록
